## 📖 项目简介

本项目是一款面向居家养老场景的AI安全预警系统，通过普通摄像头实现24小时无感监测。系统融合**姿态估计、语音情感分析、行为轨迹建模**三大技术，实现从"事后响应"向"风险前置预判"的升级。

**核心能力**：
- 🔴 **跌倒风险识别**：基于MediaPipe姿态估计 + LSTM时序模型，识别步态不稳、扶墙行走等跌倒前兆行为
- 🟡 **心理健康评估**：基于语音情感分析与活动量统计，检测抑郁、焦虑倾向
- 🔵 **诈骗行为预警**：基于大模型语义分析，识别诈骗话术与异常交互

**三级分级预警**：
| 等级 | 触发条件 | 干预动作 |
|------|----------|----------|
| 一级 | 风险分数 0.3-0.5 | 仅记录，不打扰 |
| 二级 | 风险分数 0.5-0.7 | 主动语音询问 + APP推送 |
| 三级 | 风险分数 > 0.7 | 紧急联系人通知 + 120呼叫 |

## 🎯 核心功能

| 功能模块 | 技术方案 | 输出 |
|----------|---------|------|
| 实时视频采集 | 萤石RTSP视频流拉取 | 连续帧图像 |
| 姿态估计 | MediaPipe Pose（33个关键点） | 骨骼关键点坐标 |
| 跌倒前兆识别 | LSTM时序分类模型 | 跌倒风险分数（0-1） |
| 语音情感分析 | Whisper + 情感分类模型 | 心理风险分数（0-1） |
| 诈骗话术识别 | 大模型语义分析 / 关键词匹配 | 诈骗风险分数（0-1） |
| 多模态融合 | 加权融合（0.50 + 0.25 + 0.25） | 综合风险分数 |
| 智能体决策 | 记忆模块 + 分级决策 + 大模型二次确认 | 干预指令 |
| 分级预警 | 三级干预（语音/APP/短信/呼叫） | 通知送达 |

## 🚀 快速开始

### 环境要求
- Python 3.9+
- 萤石开放平台账号（申请AppKey/Secret）
- 萤石C6/C8系列摄像头 × 1-2台

### 安装依赖
```bash
pip install -r requirements.txt

## 🎯 配备文件
# 创建 .env 文件，填入萤石平台凭证
EZVIZ_APP_KEY=your_app_key
EZVIZ_APP_SECRET=your_app_secret
EZVIZ_DEVICE_SERIAL=your_device_serial

## 🎯 启动服务
# 启动后端服务
python app.py

# 访问前端界面（开发环境）
npm run dev
