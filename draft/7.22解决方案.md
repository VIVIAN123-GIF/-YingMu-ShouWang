# “萤目守望”——多模态AI居家养老安全预警系统

## 完整解决方案（7.22重构版）

> 核心任务：以跌倒风险建立完整、可验证的前置预警范式；心理健康与诈骗风险作为证据适配场景，复用同一套个人记忆、风险推理、分级干预与回落复核机制。

> 开发范围、接口、状态机、任务与验收以《[开发冻结方案](./冻结方案/README.md)》为执行依据。

---

## 一、项目定位

比赛方案允许跌倒风险、心理健康和诈骗风险“单选或多选”。本项目主动选择三个方向，但不建设三个相互独立的系统，而是采用“一项核心任务、一套通用方法、两个扩展场景”的结构：

- **核心验证任务：跌倒风险前置防控。** 完整实现长期易感性发现、中期风险状态判断、短期临近危险干预和干预后回落复核。
- **心理健康扩展：长期行为趋势场景。** 将活动量、作息和社交行为的持续偏离接入同一套个人记忆与分级预警机制。
- **诈骗风险扩展：外部高风险交互场景。** 将非授权访客、异常停留和授权音频关键词接入同一套证据融合与家属核验机制。

本项目的核心命题不是“更快识别老人已经跌倒”，而是：

> 风险发生以前，会留下哪些连续、微小且可解释的信号？系统如何在不打扰老人的前提下，提前终止风险升级过程？

### 1.1 一句话技术定位

> “萤目守望”提出一种个体基线感知的多模态、多时标居家风险预警范式，通过“微特征连续观测—个人基线比较—上下文校正—多时标证据融合—分级干预—风险回落复核”，实现从事后检测向事前防控转变。

### 1.2 与比赛要求的对应关系

| 比赛要求 | 本项目回应 |
|---|---|
| 跌倒风险区别于跌倒动作识别 | 重点识别起身变慢、步态不稳、快速起身、低照度和高风险区域等跌倒前兆 |
| 心理健康前期风险筛查 | 仅输出长期行为趋势与关怀建议，不作抑郁症、认知症等医学诊断 |
| 诈骗风险多维识别 | 一期覆盖摄像机视野及授权收音范围内的陌生人入户和高风险交互 |
| 前置预判—过程识别—分级预警 | 长期趋势、中期状态、短期危险、分级干预和回落复核形成完整闭环 |
| 基于萤石开放平台 | 萤石视频接入、设备语音、消息推送和事件回放进入核心演示链路 |
| 可验证、可落地 | 提供参与者独立测试、连续误报测试、消融实验和可复现部署文档 |

## 二、核心故事：“张爷爷没有跌倒的第100天”

张爷爷是依据独居老人典型需求设计的**模拟用户画像**，所有长期数据和事件均通过模拟居家环境与数据回放完成，不包装为真实老年人长期临床试验。

### 2.1 开场：一段“什么都没有发生”的视频

凌晨3点07分，张爷爷从床边匆忙站起，身体晃了一下。女儿预先录制的声音从萤石设备中响起：

> “爸，别着急，先坐稳再走。”

张爷爷重新坐下，几秒后扶稳起身。画面里没有跌倒、没有救护车，也没有红色警报。

项目由此提出问题：

> 系统为什么能在这30秒里知道危险正在靠近？

随后将时间拨回100天前，依次展示个人画像、基线建立、长期趋势、高风险交互和黄金半分钟干预。

### 2.2 第零幕：安装第一天

78岁的张爷爷独居，老伴去世三年，女儿在外地工作。安装设备时，他对女儿说：

> “摄像头可以装，但别有点风吹草动就给我打电话。我不想总让你担心。”

女儿在App中完成3分钟初始问卷，登记独居情况、关节问题、既往跌倒、用药安排和起夜头晕等信息，并录制一句适老化提醒。

系统据此完成冷启动画像、隐私区域、通知等级和语音授权配置。问卷只用于风险修正，不直接产生医学结论。

### 2.3 第一幕：第1—70天，学习“平常的张爷爷”

系统静默学习张爷爷正常的起身时长、相对步速、躯干摆动、日常活动范围和常见低照度时段。老人端不产生频繁提醒，家属端仅显示基线建立进度。

> 系统首先学习的不是危险，而是张爷爷平常安全的样子。

系统形成短时30秒、中时24小时、长时7天以上的个人记忆，为后续识别偏离提供参照。

### 2.4 第二幕：第71—90天，生活半径缩小

连续阴雨天气后，恰逢老伴忌日前后，系统发现张爷爷的活动范围持续缩小、白天久坐时间增加、夜间反复起身，起身时间和步态稳定性也开始偏离个人基线。

系统没有因为一次起身变慢就报警。只有当变化连续出现，才向女儿生成黄色周报：

> “父亲近期活动范围缩小、作息规律改变，步态稳定性也持续偏离个人习惯。建议近期主动联系，了解其情绪、睡眠和身体状态。”

女儿在视频通话中得知，父亲最近经常想起老伴，持续缺乏外出和活动兴趣，夜间也睡不踏实。这个心理信息并不是系统从画面中“诊断”出来的，而是系统通过行为变化促成家属沟通后，由老人主动表达的。

在张爷爷同意后，女儿通过App完成简短心理风险筛查，并选择持续关怀。系统给出的不是疾病名称，而是“保持联系、增加陪伴；若持续或加重，建议联系家庭医生或专业人员评估”的行动建议。后续系统结合活动、作息趋势和家属反馈进行回落复核。

这里同时展示：

- 跌倒范式的长期易感性发现；
- 心理健康证据适配器对长期活动和作息趋势的复用；
- 系统观测、老人自述、家属反馈和自愿筛查的证据闭环；
- “建议关怀、自愿筛查或专业评估”而非医学诊断的适老化表达。

运动认知风险综合征（MCR）仅作为步态、认知和心理风险相关性的辅助学术背景，不能把独居、丧偶或一次步态变慢直接判定为MCR，也不使用未经验证的固定下降比例作为MCR诊断阈值。

### 2.5 第三幕：第96天，“免费健康服务”来访

一名自称提供免费健康检测的人员进入客厅。系统开始并未报警，因为正常快递、家政和亲友来访不应被误判。

随着事件发展，系统发现非授权访客长时间停留，授权音频中出现“保证收益”“验证码”“现在转账”等高风险词汇，同时张爷爷在客厅频繁走动。

女儿收到的是一张身份核验卡，而不是“父亲正在被骗”的武断结论：

> “检测到非授权访客长时间停留，并出现高风险交互特征，建议确认来访者身份。”

女儿联系父亲完成身份核验，风险事件随后回落。该场景证明诈骗风险只需增加外部交互证据适配器，即可复用统一证据、状态机、家属通知和回落复核能力。

### 2.6 第四幕：第100天凌晨，黄金半分钟

凌晨3点07分，系统综合掌握：

- 长期：近期步态稳定性与起身状态持续偏离个人基线；
- 中期：当前处于低照度、高风险起夜时段；
- 短期：快速起身后躯干明显摇晃，并准备进入昏暗通道。

风险状态升级为橙色，萤石设备立即播放女儿预先录制的提醒，同时向家属记录事件。张爷爷重新坐下后，系统继续观察，确认其姿态和移动状态恢复稳定，才将风险水位回落。

核心演示必须真实跑通：

> 萤石视频接入 → 姿态及环境微特征 → 个人基线比较 → 长中短证据融合 → 橙色风险 → 设备语音 → 姿态恢复 → 风险回落

### 2.7 故事结论

> 我们没有分别搭建跌倒、心理和诈骗三个系统。我们首先通过跌倒建立了一种通用预警范式：连续观测、个人基线、多时标融合、分级干预和回落复核。心理健康和诈骗风险只是接入不同证据，后面的记忆、推理和干预能力全部复用。

完整答辩故事、台词和三线映射见《7.22三线融合叙事.md》。

## 三、统一预警范式

### 3.1 一套共享内核

系统只保留：

- 一个老人档案；
- 一套长中短个人记忆；
- 一种统一证据结构；
- 一个风险状态机；
- 一个家属端事件时间轴；
- 一套分级干预和回落复核机制。

不同风险方向不建设独立系统，仅替换证据适配器。

### 3.2 统一数据对象

| 数据对象 | 主要字段 | 作用 |
|---|---|---|
| Observation（观测） | 老人标识、时间、空间、模态、特征值、数据质量 | 记录感知层原始结果 |
| Evidence（证据） | 风险标签、基线偏离、置信度、上下文、解释 | 将不同模态转换为统一风险证据 |
| RiskEvent（风险事件） | 风险水位、证据链、提前量、处置建议 | 驱动预警、展示与干预 |
| InterventionResult（干预结果） | 设备执行、老人状态、家属反馈、是否回落 | 完成事件闭环并支持复盘 |

### 3.3 五步判断流程

1. **多模态证据生成**：任务适配器分别输出行为、环境、活动和外部交互证据；
2. **个人基线比较**：判断当前状态相对本人历史状态的偏离，而非只使用人群统一阈值；
3. **上下文与质量校正**：根据遮挡、照度、摄像机角度、辅助器具和合理生活情境调整置信度；
4. **多时标融合与升级**：在短时、中时和长时窗口中聚合证据，通过统一状态机确定风险水位；
5. **干预与回落复核**：执行干预后持续观测，确认风险真正解除后才关闭事件。

### 3.4 三时标记忆

| 时间尺度 | 建议窗口 | 主要作用 |
|---|---|---|
| 短时记忆 | 最近30秒 | 快速起身、摇晃、进入危险区域等临近危险 |
| 中时记忆 | 最近24小时 | 当日状态、低照度时段、连续异常和外部事件 |
| 长时记忆 | 7天及以上 | 步态、活动、作息和交互习惯的个人基线与趋势 |

冷启动阶段使用问卷和初始观测；3天形成初步基线，7天形成滚动基线。只有绿色正常时段的数据可进入基线更新，预警时段和人工确认的异常样本不得自动污染基线。

## 四、任务证据适配器

### 4.1 跌倒风险适配器（核心任务）

| 证据类别 | 一期实现 |
|---|---|
| 起身行为 | 起身时长、快速起身、起身后停顿与摇晃 |
| 步态行为 | 相对步速、左右对称性、躯干摆动、连续性 |
| 环境上下文 | 照度、昼夜时段、人工标定的高风险区域、障碍占用 |
| 数据质量 | 遮挡比例、关键点连续性、摄像机角度和画面清晰度 |

固定摄像机完成一次空间标定后再估计相对移动速度；未标定时不宣称厘米级步长或绝对速度精度。

### 4.2 心理健康证据适配器

| 证据类别 | 一期实现 |
|---|---|
| 活动趋势 | 每日活动时长、房间转换次数、活动范围 |
| 作息趋势 | 起床、午休、夜间活动等规律偏离 |
| 人工确认 | 老人自述、家属关怀反馈 |
| 自愿信息 | 初始问卷和经本人同意的简短风险筛查 |
| 回落证据 | 后续趋势是否恢复、家属是否完成联系或专业咨询 |

输出仅包括“长期行为趋势变化”“建议家属联系”“建议自愿筛查或专业评估”。系统不输出抑郁症、认知症或MCR诊断，单纯活动减少也不得直接解释为心理问题。

### 4.3 诈骗风险证据适配器

| 证据类别 | 一期实现 |
|---|---|
| 人员事件 | 非家庭授权人员出现、停留时间和活动区域 |
| 对话事件 | 在明确授权下进行本地语音转写和高风险关键词检测 |
| 行为事件 | 老人异常踱步、频繁寻找物品等可解释行为变化 |

一期仅覆盖摄像机视野和收音范围内的居家入户及对话场景，不宣称读取陌生号码、监听全部手机通话、判断真实转账或自动阻断支付。

### 4.4 共享关系

| 通用步骤 | 跌倒核心任务 | 心理扩展 | 诈骗扩展 |
|---|---|---|---|
| 特征输入 | 起身、步态、环境 | 活动、作息、问卷 | 访客、停留、话术 |
| 个人基线 | 正常步态和起身 | 正常活动规律 | 正常访客与交互 |
| 上下文 | 遮挡、照度、辅助器具 | 生病、外出、节假日 | 亲友、快递、家政 |
| 风险输出 | 跌倒风险水位 | 关怀/筛查建议 | 身份核验建议 |
| 干预 | 设备语音、家属通知 | 周报、家属联系 | 家属核验 |
| 回落 | 姿态和移动恢复 | 趋势恢复或反馈 | 身份确认或交互结束 |

## 五、系统架构

### 5.1 设备与平台层

- 萤石摄像机视频接入；
- 萤石设备语音或已确认可用的对讲能力；
- 萤石开放平台消息和事件能力；
- PC端或本地服务器完成一期推理；
- 家属Web端展示风险时间轴、证据链和处置结果。

智能灯光、社区系统和急救平台联动仅在实际设备与接口验证后作为扩展，不进入一期必交闭环。

### 5.2 感知层

- 姿态估计：提取人体关键点、起身、摇晃和移动特征；
- 人员与轨迹：识别人员数量、区域停留和活动轨迹；
- 环境特征：统计照度和人工标定的高风险区域；
- 授权音频：本地转写诈骗高风险词汇，不将心理诊断建立在持续监听上。

### 5.3 记忆与决策层

- 结构化保存个人画像与脱敏特征；
- 维护短、中、长三类时间窗口；
- 通过稳健统计或验证集标定方式计算个人偏离；
- 采用置信度加权融合与有限状态机输出绿、黄、橙、红风险水位；
- 多智能体或大模型不进入安全风险最终判定链路。

### 5.4 应用与执行层

家属端只保留一个统一时间轴，风险事件用跌倒、心理和诈骗证据标签区分，不设计三个独立后台。

| 风险等级 | 系统行为 | 老人侧 | 家属侧 |
|---|---|---|---|
| 绿色 | 更新正常基线 | 不打扰 | 无通知 |
| 黄色 | 记录长期趋势 | 原则上不即时提醒 | 周报和关怀建议 |
| 橙色 | 启动柔性干预并观察回落 | 短句、单任务语音 | 事件通知和建议动作 |
| 红色 | 持续监测并升级人工接管 | 清晰确认问答 | 紧急联系人接管 |

一期不自动拨打120。是否联系急救机构由授权照护人根据现场情况决定。

## 六、适老化与隐私设计

### 6.1 适老化原则

- 低风险不打扰；
- 先给具体动作，再解释原因；
- 慢速、短句、一次只说一件事；
- 优先使用老人熟悉的家属录音；
- 不使用“你要跌倒了”“你被骗了”“你得了抑郁症”等标签化表达；
- 允许老人和家属调整通知等级、暂停部分能力和撤回授权；
- 通过冷却时间和置信度门槛控制提醒疲劳。

### 6.2 隐私合规

- 明确视频、音频、访客识别和家属查看权限；
- 原始视频默认不长期保存，仅保留脱敏特征和必要事件片段；
- 音频分析必须取得明确授权并优先本地处理；
- 不在卫生间内部部署摄像机，只监测门口及通行区域；
- 人脸白名单和特征数据本地加密保存；
- 测试参与者签署知情同意，材料展示全部脱敏；
- 提供数据删除、授权撤回和访问日志。

## 七、数据与验证

### 7.1 公共数据的正确用途

- URFD视频可用于跌倒动作识别、姿态模型调试和事后检测基线；
- SisFall为腰部惯性传感器数据，可用于研究对照，但不能直接证明摄像头方案性能；
- 两者都不能直接证明个人长期基线和跌倒前置预判能力；
- 前兆预测、多时标融合和干预闭环必须通过自采模拟场景验证。

### 7.2 最低数据要求

| 方向 | 最低要求 | 验证内容 |
|---|---|---|
| 跌倒核心 | 不少于8名志愿者、96段风险前兆和易混淆正常行为 | 前兆识别、基线偏离、风险升级和回落 |
| 心理扩展 | 不少于12组多日活动趋势回放 | 长期趋势适配，不验证临床诊断 |
| 诈骗扩展 | 不少于40段正常和高风险来访/对话 | 证据适配、身份核验和事件回落 |
| 连续运行 | 不少于12小时正常活动 | 误报率、稳定性、延迟和资源占用 |

训练、验证和测试必须按参与者划分，避免同一人的片段同时进入训练集和测试集。

### 7.3 评价指标

| 层级 | 指标 |
|---|---|
| 单项识别 | 精确率、召回率、F1、混淆矩阵 |
| 前置预警 | 高风险窗口召回率、提前量、误报频率、分级一致性 |
| 干预效果 | 指令送达率、动作响应率、风险回落时间、闭环完成率 |
| 系统效能 | 端到端P95延迟、连续运行时长、资源占用 |

一期工程目标：

- 跌倒主任务F1不低于0.80；
- 高风险窗口召回率不低于0.80；
- 端到端P95延迟不高于2秒；
- 正常连续场景误报不高于0.5次/小时；
- 萤石提醒指令送达率不低于95%。

这些数值是研发验收目标，不得在实验完成前写成已实现结果。

### 7.4 必做消融实验

1. 统一人群阈值与个人基线比较；
2. 单模态与多模态融合比较；
3. 无上下文校正与有上下文校正比较；
4. 无回落复核与完整闭环比较。

消融实验优先在跌倒主任务完成，心理和诈骗只验证适配能力，不追求与主任务相同的研究深度。

## 八、技术边界

一期明确不承诺：

- 通过普通摄像头可靠识别透明水渍；
- 自动读取陌生电话号码或监听所有手机通话；
- 自动判断老人已经转账；
- 自动阻断支付；
- 未经人工确认自动拨打120；
- 根据单次异常诊断MCR、抑郁症或认知症；
- 在没有真实测试的情况下声称事故率下降；
- 在线自动学习并直接改变安全模型。

## 十二、最终答辩总结

> “萤目守望”没有把跌倒、心理和诈骗做成三个拼接功能。我们首先用跌倒风险建立了一套完整的通用预警范式：连续观测老人平常安全的样子，在长期发现趋势、在中期抬高警戒、在短期阻断危险，并在干预后确认风险真正解除。心理健康和诈骗风险只需接入新的证据适配器，即可复用同一套个人记忆、推理、预警和回落机制。我们理解的预警，不是更快地看到事故发生，而是让本来可能发生的事故没有发生。”
