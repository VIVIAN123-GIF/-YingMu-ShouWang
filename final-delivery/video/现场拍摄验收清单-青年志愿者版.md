# 现场拍摄验收清单（青年志愿者版）

## 设备与画面

- [ ] C6c 在线，机位编号为 `C6c-pos01`，视野覆盖全身、双脚、座椅和行走区。
- [ ] 地面清空、防滑鞋、稳固座椅和安全员到位；禁止真实摔倒、闭眼行走、冲刺和强行失衡。
- [ ] 主摄像机与 OBS 屏幕录制连续运行，分辨率、帧率和日期一致。

## 系统闭环

- [ ] 高风险链路完整显示：Observation → Evidence → RiskEvent → 橙色 → 干预 → 观察 → RESOLVED。
- [ ] 低风险链路显示绿色，并能与高风险事件并排对照。
- [ ] 风险分数贡献可展开，使用实际规则版本和实际字段。
- [ ] `MOCK`、`RECORDED_REPLAY`、`LIVE_DEVICE`、`EXPERIMENT_RESULT` 标签清晰可见。
- [ ] 实验指标与 `experiments/three-participant/results/final/experiment-results.json` 一致。

## 授权与隐私

- [ ] 每位志愿者有书面授权记录，视频只使用参与者编号。
- [ ] 姓名、电话、账号、Token、门牌、支付页面和绝对路径均未入镜。
- [ ] 诈骗场景使用虚构身份、金额和验证码；心理场景只展示关注建议，不作诊断。
- [ ] 外部服务失败时能展示明确的降级状态和失败日志。

## 说词边界

- [ ] 明确说明青年志愿者是受控模拟，不代表老年人临床表现。
- [ ] 不把模拟趋势或录制回放说成实时识别。
- [ ] 不宣称未经项目实际结果支持的准确率、召回率、临床或司法结论。
