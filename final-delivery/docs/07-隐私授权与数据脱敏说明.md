# “萤目守望”隐私授权与数据脱敏说明

## 1 最小化原则

系统只采集完成风险评估所需的视频片段、姿态关键点、动作特征和授权语言摘要。默认不上传原始图片、视频或音频给大模型，不采集身份证号、电话号码、银行卡、家庭IP或永久视频地址。

## 2 授权管理

三名参与者分别使用匿名编号P01-P03。视频、肖像、实验数据及安全确认材料只有在对应授权范围得到确认后，方可进入评审材料或演示；授权记录应注明允许用途、演示画面形式、保存期限、删除方式和撤回记录。当前公开材料不把授权归档状态表述为已经完成，未取得相应确认或有未授权人员进入画面的片段不得使用。

## 3 存储边界

- 原始视频：仓库和OneDrive外的受控目录，或Git忽略的private目录。
- 签字原件：signed-consent私有目录，不进入公开代码包。
- 设备凭证：只在`.env.local`或受控密钥服务。
- 临时URL：只在后端进程内使用，不写日志和数据库公共字段。
- 提交材料：只包含匿名编号、统计量、脱敏截图和必要的授权说明。

## 4 模型与接口脱敏

Qwen请求只包含匿名内部标识、RiskEvent、Evidence解释摘要、基线状态、时间范围、干预状态和能力矩阵。不得包含原始媒体、完整转写、设备序列号、Token、URL、路径或storage_key。Provider返回非法内容时不向前端展示并使用模板降级。

## 5 来源与模拟标识

页面、日志、报告和视频统一使用`LIVE_DEVICE`、`RECORDED_REPLAY`、`PUBLIC_DATASET`和`MOCK`。受控动作、长期趋势和诈骗来访场景标记`simulated=true`。心理页面不作医学诊断，诈骗页面不把访客直接定性为诈骗人员。

## 6 提交前检查

- [ ] 删除`.env`、私有数据库、临时URL和本地绝对路径。
- [ ] 扫描Token、Secret、验证码和完整设备序列号。
- [ ] 截图和视频模糊人脸、门牌、聊天、证件和其他私人内容。
- [ ] 检查授权范围与实际演示画面一致。
- [ ] 记录保存截止日期和提交后的删除负责人。
- [ ] 确认撤回素材已从报告、视频和备份中移除。
- [ ] 逐项核对P01-P03授权记录状态，未确认项不得标记为已完成。
