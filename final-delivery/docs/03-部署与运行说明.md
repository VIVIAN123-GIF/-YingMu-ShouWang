# “萤目守望”部署与运行说明

适用版本：Windows一键发布候选版

## 1 最快启动

解压`萤目守望-Windows.zip`后，双击`start-demo.cmd`。程序会创建独立演示数据库，启动API和两个Worker，写入明确标记为Mock的固定闭环，并打开浏览器。

停止程序：回到启动窗口按`Ctrl+C`。程序应关闭全部子进程；日志保存在`runtime/logs/`。

## 2 命令行入口

```powershell
YingMuShouWang.exe demo
YingMuShouWang.exe live
YingMuShouWang.exe server
YingMuShouWang.exe alarm-worker
YingMuShouWang.exe agent-worker
```

`demo`用于离线评审演示；`live`用于授权实机环境；后三个命令用于诊断。默认地址为`http://127.0.0.1:8000`，健康检查为`/health`。

## 3 真实设备配置

从`config/.env.example`创建`config/.env.local`，只在本机填写AppKey、AppSecret、设备序列号、Webhook密钥和授权记录。禁止提交或发送该文件。

真实模式至少要求：

```text
EZVIZ_APP_KEY
EZVIZ_APP_SECRET
EZVIZ_DEVICE_SERIAL
```

真实模式拒绝`EZVIZ_WEBHOOK_ALLOW_UNSIGNED_TEST=true`。服务端语音只有在真实日志验证后才能设置`EZVIZ_VOICE_VERIFIED=true`。

## 4 源码运行

```powershell
python -m pip install -r backend/requirements.txt
python -m backend.db.init_db
python -m scripts.yingmu_launcher demo
```

前端开发模式：

```powershell
cd frontend
npm ci
npm test -- --run
npm run dev
```

## 5 构建Windows发布包

在仓库根目录执行：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/build_windows_release.ps1
```

脚本执行前端测试和生产构建，安装固定版PyInstaller，生成onedir程序，启动完整Demo栈并写入固定Mock闭环，验证首页后正常退出，计算SHA-256清单并压缩为`output/windows/萤目守望-Windows.zip`。

## 6 验收检查

- 在未安装Python和Node的Windows电脑上解压并启动；
- 3分钟内打开首页，九个一级入口可访问；
- 演示页面显示Mock或回放标签；
- 关闭后没有残留Worker；
- 发布包敏感扫描无发现；
- `MANIFEST-SHA256.txt`覆盖包内文件。

## 7 故障定位

启动失败时先查看`runtime/logs/demo.log`和三个进程日志。端口占用时使用`demo --port 8010`。模型缺失、配置缺项或真实模式启用无签名Webhook时，启动器会明确退出，不会自动降级为真实成功。
