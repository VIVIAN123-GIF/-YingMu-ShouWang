# “萤目守望”第三方数据、模型与开源软件清单

文档状态：已按当前源码锁定直接依赖版本；最终发布构建后仍需以锁文件和包内清单复核间接依赖及许可证文本。

## 1 公开数据与模型

| 名称 | 用途 | 分发策略 |
|---|---|---|
| UR Fall Detection Dataset | 公开数据姿态管线独立复核 | 不随程序分发，保留来源与许可说明 |
| MediaPipe Pose Landmarker Heavy | 33点姿态估计 | 随发布包分发模型文件和SHA-256，保留官方来源 |
| 萤石开放平台 | 设备状态、Webhook、抓拍及H.264媒体获取 | 不分发凭证，按平台条款调用 |
| 阿里云百炼Qwen `qwen3.6-flash` | 对脱敏结构化风险事实生成解释 | 不分发凭证；模型不参与风险等级裁决 |

## 3 分发与许可边界

- URFD原始数据不随源码或程序分发，只保留官方来源、文件哈希和聚合结果；使用范围以数据集原始许可为准。
- MediaPipe模型只在确认官方来源、模型文件SHA-256及随包许可文本一致后进入最终发布包。
- 萤石和Qwen凭证、临时地址、调用签名及私有日志不进入公开包。
- 最终提交前根据Python安装清单、`package-lock.json`和二进制包生成完整第三方许可证清单；对尚未核验的许可证不作推断性声明。

项目团队独立完成风险状态机、统一证据契约、个人基线适配、前后端应用、萤石接口封装、实验协议和交付材料。第三方模型与库仅作为明确列出的基础工具，不将其成果冒充团队原创算法。
