# 01 范围与验收

## 一、产品范围

### 1.1 核心用户

| 角色 | 主要需求 |
|---|---|
| 独居老人 | 免穿戴、低打扰、隐私可控、危险前获得简单明确的帮助 |
| 异地子女 | 不必持续盯屏，及时获得可解释风险和明确处置建议 |
| 研发与评委 | 系统可执行、效果可验证、数据可复现、能力边界清晰 |

### 1.2 核心价值

传统跌倒检测回答“老人是否已经跌倒”；本项目重点回答：

- 老人是否正在持续偏离个人安全基线；
- 当天是否处于更高风险状态；
- 临近跌倒前是否出现可干预信号；
- 干预后风险是否真正解除。

## 二、必须完成的P0范围

### 2.1 跌倒主任务

- 单台萤石C6c实机接入，型号CS-C6c-V101-1J4WF（4mm）；
- 实机、预录回放、公开数据和Mock输入共用DeviceAdapter；
- MediaPipe姿态估计；
- 起身、相对步速、躯干摇摆和快速起身特征；
- 照度、昼夜时段和人工标定高风险区域；
- 短时30秒、中时24小时、长时7天以上个人记忆；
- 个人基线偏离；
- 绿、黄、橙、红状态机；
- 已核验的萤石语音或消息干预；接口不可用时记录失败并调用声明为Mock的降级工具；
- 姿态恢复和风险回落；
- 统一事件日志与场景回放。

### 2.2 心理健康适配场景

- 使用同一摄像机集中拍摄的模拟实验素材或多日趋势回放，不占用实时实机链路；
- 活动范围、活动时长和昼夜节律趋势；
- 黄色周报；
- 家属关怀确认；
- 经本人同意的简短风险筛查入口；
- 家属反馈与趋势回落；
- 仅输出关怀、筛查或专业评估建议。

### 2.3 诈骗风险适配场景

- 使用同一摄像机集中拍摄并明确标注的模拟来访/对话素材；
- 非授权访客出现；
- 访客停留时间；
- 经授权的本地语音转写和高风险关键词；
- 家属身份核验卡；
- 核验完成后的事件回落。

### 2.4 统一应用

- 一个老人档案；
- 一个风险水位；
- 一个事件时间轴；
- 一套证据解释卡；
- 一套干预结果页面；
- 一套日/周摘要。

## 三、允许完成的P1范围

只有P0全部可运行后才允许开发：

- LSTM或其他时序模型与规则基线的对照实验；
- 家属录音管理；
- 更精细的访客白名单；
- 自动生成自然语言周报；
- 更丰富的场景回放和可视化；
- PC推理性能优化。

P1功能不允许阻塞P0联调、实验和材料提交。

## 四、明确不做

8月31日前不进入正式范围：

- 普通摄像头识别透明水渍；
- 读取陌生电话号码；
- 监听全部手机通话；
- 判断是否真实转账；
- 自动阻断支付；
- 未经人工确认自动拨打120；
- 根据单次异常诊断MCR、抑郁症或认知症；
- 大模型直接决定红色安全预警；
- 在线自动学习并直接修改安全阈值；
- 三套独立的跌倒、心理和诈骗后台；
- 未确认硬件与接口的智能灯光、社区平台和急救平台联动。
- 多摄像机同时覆盖卧室、客厅和其他空间；
- 向公网直接暴露家庭摄像机IP、路由器端口或未经鉴权的视频流；

## 五、核心演示验收

### 5.1 黄金半分钟

必须使用唯一实机现场完成，或通过该实机产生的可信录屏完整展示：

1. 视频输入；
2. 快速起身和摇晃Evidence；
3. 个人基线偏离；
4. 长、中、短证据链；
5. 橙色风险事件；
6. 已核验萤石工具执行；若语音/消息能力未开放，展示真实失败记录与Mock降级执行；
7. 老人重新坐稳；
8. 观察期；
9. 风险回落；
10. 家属端处置摘要。

任何一个环节只存在于PPT而不存在于系统，均视为未完成。

### 5.2 心理场景

必须展示：

- 页面明确标记“模拟实验回放”；
- 多日活动和作息趋势；
- 黄色风险和证据解释；
- 家属关怀确认；
- 自愿筛查或专业建议；
- 后续趋势或家属反馈进入回落复核。

### 5.3 诈骗场景

必须展示：

- 页面明确标记“模拟实验回放”；
- 非授权访客和停留证据；
- 至少一个高风险关键词证据；
- 家属身份核验卡；
- 核验完成；
- 事件回落。

## 六、工程验收指标

| 指标 | 工程目标 | 说明 |
|---|---:|---|
| 跌倒主任务F1 | 不低于0.80 | 最终以测试集实测为准 |
| 高风险窗口召回率 | 不低于0.80 | 按参与者独立测试 |
| 端到端P95延迟 | 不高于2秒 | 从证据产生到干预请求 |
| 正常场景误报 | 不高于0.5次/小时 | 至少12小时连续测试 |
| 已核验萤石指令送达率 | 不低于95% | 仅统计实际开放且调用成功过的接口，记录成功、失败和重试 |
| 核心闭环复现率 | 100% | 固定脚本连续复现3次 |

这些是验收目标，未完成实验前不得写成已实现结果。

## 七、数据与实验验收

| 数据 | 最低要求 |
|---|---|
| 跌倒主任务 | 不少于8名志愿者、96段前兆与正常干扰场景 |
| 心理趋势 | 不少于12组多日趋势回放 |
| 诈骗场景 | 不少于40段正常与风险来访/对话 |
| 连续运行 | 不少于12小时正常活动 |

训练、验证和测试按参与者划分。必须保存模型版本、规则版本、场景配置、标注、原始结果和统计脚本。

所有自采素材必须记录来源类型、模拟标识、机位、光照、音频授权和可使用范围。张薇停止实机后，算法与前端仍须能够使用历史片段复现结果。

## 八、材料验收

最终提交包必须包含：

- 研究报告；
- 源代码与可执行程序；
- 部署和运行说明；
- 系统设计文档；
- 接口规范；
- 数据及标注说明；
- 功能与性能测试报告；
- 消融实验；
- 隐私授权与脱敏说明；
- 演示视频和离线备用回放。
