# 07 单设备异地协作与实机管理

## 一、适用条件

- 硬件：一台萤石C6c室内云台摄像机，型号CS-C6c-V101-1J4WF（4mm）；
- 设备状态：尚未到货，预计一周内寄到张薇处；
- 团队状态：成员分散在不同地点，除张薇外均按远程方式参与；
- 实机优先级：跌倒黄金半分钟主闭环优先于心理和诈骗扩展场景。

## 二、冻结协作模式

> 张薇现场保管并执行动作 → 摄像机或现场电脑采集 → 萤石云/鉴权后端/授权素材 → 远程成员开发和验证

1. 张薇是唯一设备保管人、默认现场操作人和家庭测试区管理员；
2. 不共享萤石主账号密码、AccessToken、家庭IP或路由器信息；
3. 远程成员通过官方云端能力、项目后端、授权事件片段或本地回放开发；
4. 跌倒最终使用`LIVE_DEVICE`，心理和诈骗使用`RECORDED_REPLAY`；
5. 到货前统一使用`PUBLIC_DATASET`、本地视频和`MOCK`，不得等待硬件；
6. 未完成调用日志的取流、抓图、云台、消息、语音/对讲等能力一律标记“待核验”。

## 三、三级远程链路

### 3.1 首选：萤石官方云端

`C6c → 萤石云端 → FastAPI → 算法/前端`

到货后验证设备在线、实时播放、抓图、云录制、云点播、云台、音频、语音/对讲、消息、并发限制、地址有效期、频率和费用。每项保存请求、脱敏响应、延迟和失败日志。

### 3.2 备用：张薇现场电脑网关

`C6c → 张薇现场电脑 → 截图/事件片段/模拟帧 → FastAPI`

网关至少提供设备状态、最新授权截图、片段上传、模拟实时帧、操作日志、一键停止和断网缓存。不得直接向公网暴露摄像机或家庭路由器端口。

### 3.3 最低降级：录制后上传

`按脚本录制 → 云存储/授权文件 → 离线算法 → Evidence → 状态机与前端`

降级顺序固定为：官方云端→现场网关→云存储事件片段→本地视频→Mock Evidence。切换链路时必须同步更新`source_mode`。

## 四、现场操作边界

### 4.1 张薇负责

- 开箱、联网、绑定、固定测试区和机位标定；
- 按审批脚本执行起身、走动、语音和环境调整；
- 记录动作、时间、机位、光照、音频和模拟标识；
- 上传授权素材并设置可访问范围；
- 测试结束后停止采集或遮挡镜头。

### 4.2 张薇不负责

- 替算法成员调试MediaPipe、Whisper或标注代码；
- 全天保持摄像机开放；
- 接受未提交完整脚本的临时拍摄；
- 人工逐帧整理所有素材；
- 向团队分发个人主账号或永久有效播放地址。

## 五、实机预约规则

实机需求必须进入飞书“实机预约表”，至少提前一天提交：测试目的、模块、动作步骤、机位、光照、重复次数、是否录音、预计用时、命名规则、验收标准和失败后所需日志。

申请缺少动作、环境条件或验收标准时，状态保持“待补充”，不得拍摄。P0跌倒优先；心理和诈骗合并为集中拍摄批次。补拍必须关联原预约并写明失败片段和失败原因。

## 六、数据与隐私

文件名统一为：`日期_场景_动作_光照_模态_序号`。

示例：`0729_FALL_快速起身摇晃_低照度_视频音频_01.mp4`。

每段素材必须记录：模拟性质、拍摄时间、机位、光照、动作、音频授权、访问成员、保存期限、是否允许进入PPT/答辩视频。家庭私人区域、无关人员和敏感物品不得入镜；连续家庭原始视频默认不保存。

## 七、到货后三日验收

### 第1天：基础能力

- 开箱、型号、供电、联网和设备绑定；
- 在线画面、抓图、录制、播放、分辨率、夜视和延迟；
- 形成已验证/待验证/不可用能力矩阵。

### 第2天：算法样例

- 正常、缓慢、快速起身；
- 起身后稳定与摇晃；
- 正常和低照度行走；
- 正常访客与高风险话术模拟；
- 正常活动与低活动趋势模拟。

每类先录少量样例，由赵勇或常易铭当天远程验收后再批量采集。

### 第3天：远程闭环

`实机/云端视频 → 特征 → Evidence → RiskEvent → 干预 → 恢复Evidence → RESOLVED`

固定脚本连续复现3次，保存接口日志、算法输出、页面截图、事件视频、录屏和失败降级记录。

## 八、到货延期处理

若7月30日前仍未到货，7月31日继续使用Mock和本地视频完成端到端验收。设备到货后再进行实机替换，不返工统一接口、状态机和前端。
