# “萤目守望”心理趋势与诈骗核验详细拍摄脚本

现场执行与工期评估版 v1.0｜适用对象：项目负责人、导演/记录员、设备与算法复核人员、授权参与者

> 当前团队按3名现场人员、晚间2-3小时条件执行时，请使用[《心理趋势与诈骗核验最小现场拍摄方案》](./心理趋势与诈骗核验最小现场拍摄方案.md)。本文保留为人员与时间充足时的完整参考，不再作为当前推荐排期。

> 本脚本用于受控工程场景验证，不拍摄真实心理疾病、真实诈骗案件或真实财产交易，不要求老人参与。所有出镜和出声人员必须是已签署授权的健康成年人。所有素材统一标记为`RECORDED_REPLAY/simulated=true`，不得描述为自然发生的居家事件、医学诊断数据或真实诈骗案件。

## 1. 先做时间与条件判断

### 1.1 三档执行方案

| 方案 | 心理素材 | 诈骗素材 | 实际源视频数 | 现场时间 | 后处理时间 | 可支持的对外结论 |
|---|---:|---:|---:|---:|---:|---|
| A 推荐验证版 | 3人×4组，共12组 | 24段 | 39段 | 8-10小时 | 5-8小时 | 可报告场景触发、误触发、Evidence完整率和闭环成功率 |
| B 压缩验证版 | 保留12组 | 12段 | 27段 | 5.5-7小时 | 3-5小时 | 心理可做完整场景统计；诈骗只能报告小样本初步结果 |
| C 仅演示版 | 1人4组 | 5段 | 10段 | 2.5-3.5小时 | 2-3小时 | 只能证明功能可运行，不报告稳定触发率或误触发率 |

说明：心理12组对应12个实验场景，不等于只生成12个MP4。每名参与者的“昼夜节律变化”需要日间和模拟夜间两段素材，因此A/B版心理部分共15个源视频。

A版心理素材净时长约34.5分钟，诈骗素材净时长约42分钟，合计约76.5分钟。现场总时间还包括授权、台词预演、换装、区域复位、文件检查、算法冒烟、休息和约20%的补拍缓冲，因此不能按净录像时长估算人力。

### 1.2 推荐版总工作量

| 工作 | 预计耗时 | 是否必须在现场完成 |
|---|---:|---|
| 授权确认、角色分配、台词预演 | 45-60分钟 | 是 |
| C6c机位、区域和音频校准 | 45分钟 | 是 |
| 3段冒烟小样与算法快速复核 | 30分钟 | 是 |
| 心理趋势15段源视频 | 2-2.5小时 | 是 |
| 诈骗核验24段源视频 | 2.5-3.5小时 | 是 |
| 现场抽查、补拍和双份备份 | 1-1.5小时 | 是 |
| SHA-256、台账和算法批处理 | 2-3小时 | 否 |
| 后端闭环、统计与截图 | 3-5小时 | 否 |

建议至少预留一个8-10小时的完整拍摄日，并在最终材料制作前保留一个完整后处理日。现场可用时间少于8小时时不要执行A版。

> 工程前置成本不包含在上表内。当前正式风险引擎仍以跌倒规则为主；在报告心理/诈骗闭环成功率前，还需要补齐按风险域分派的决策策略、`trend_recovered`恢复规则和批量场景统计脚本。建议另预留1-2个开发人日，并在开拍前先冻结人工预期和规则版本。即使代码尚未完成，也可以先拍摄，但不能在闭环代码和复跑结果完成前录制最终结论旁白。

## 2. 能力边界与统一口径

### 2.1 心理趋势

真实录像只验证以下客观行为量是否能被提取：

- 访问区域数；
- 区域转换次数；
- 日间/模拟夜间活动差异；
- 下降后恢复正常活动的行为表现。

“7日个人基线+第8日变化”由明确标记为`MOCK`的脱敏日汇总JSON验证。不得把同一天拍摄的录像复制成7天并宣称真实连续监测。

对外表述统一为：

```text
授权录像验证区域轨迹和活动特征提取；
模拟日汇总验证多日趋势规则；
结果只提示生活行为变化，不作抑郁、认知症或其他医学诊断。
```

### 2.2 诈骗核验

访客是否“授权”由场景台账中的人工名单状态给出，不宣称人脸识别已经验证。语音只使用授权台词或合成语音，系统只产生高风险交互线索和家属核验建议。

对外表述统一为：

```text
系统发现访客、停留和授权转写中的风险组合线索，
由家属完成身份核验；系统不判断真实诈骗、转账结果或法律责任。
```

## 3. 人员、角色与最低配置

### 3.1 最低人员

| 角色 | 最低人数 | 责任 |
|---|---:|---|
| 导演兼台账记录员 | 1 | 报场次、计时、记录人工真值、控制补拍 |
| 设备兼算法复核员 | 1 | C6c、录音、文件检查、冒烟算法复核 |
| “居家人员”演员 | 1 | 完成心理行为和诈骗对话 |
| “访客”演员 | 1 | 扮演授权访客和未登记访客 |

推荐再增加1名现场隐私与安全复核人员。心理趋势A版最好使用P01、P02、P03三名参与者；诈骗场景可以复用其中一人为居家人员，另一人为访客。

同一访客演员可以分别扮演“授权”和“未登记”角色，因为授权状态来自场景台账，不来自生物识别。为了评委容易理解，两个角色应使用不同外套或文件夹，但不得把服装颜色作为算法输入。

### 3.2 授权要求

现有跌倒实验授权内容不足以自动覆盖访客演绎、双人对话和语音转写。开拍前必须额外确认：

- 同意采集面部、身体动作和声音；
- 同意系统对授权语音执行脱敏转写和关键词匹配；
- 同意在比赛报告和演示视频中使用原画、人脸模糊画面或骨架画面中的选定形式；
- 知晓台词为虚构情节，不代表本人真实健康、财务或社会关系；
- 知晓可以在最终提交前撤回授权；
- 原始素材保存位置、保存截止日期和删除方式已经填写。

未签署授权的人不得出现在画面或录音中。

## 4. 场地、机位、区域和道具

### 4.1 固定区域

沿用`scene-living-room-v1`的三个区域：

```text
画面左侧 0%-28%   doorway
画面中部 28%-78%  living_room
画面右侧 78%-100% corridor
```

用不反光胶带在地面标记`D`、`L`、`C`三个区域中心点和跨区路线。实际拍摄前必须根据画面重新核对多边形，不能只照搬示例像素坐标。

### 4.2 机位与画面

- 使用同一台C6c、同一机位、同一朝向；关闭云台追踪、巡航和数码变焦。
- 主、子码流保持H.264；建议1920×1080、25或30 FPS，全部素材一致。
- 人物全身占画面高度约55%-80%，头、脚和主要区域边界始终可见。
- 摄像机高度约1.0-1.3米；居家人员与访客均在主要动作阶段完整入画。
- 模拟夜间场景可以降低环境亮度，但必须保证人员可追踪、路线无障碍；不得为了“夜间效果”制造跌倒风险。

### 4.3 道具

- 稳定椅子1把；
- 无真实机构名称的空白文件夹或宣传单；
- 处于飞行模式、无真实聊天和支付页面的道具手机；
- 虚构验证码卡片，例如`000000`；
- 两件明显不同但不影响识别的访客外套；
- 计时器、场记板、授权表和台账；
- 至少20GB可用的受控存储空间和第二份备份介质。

禁止出现真实银行卡、身份证、家庭住址、门牌、快递单、支付二维码、真实验证码、真实联系人和私人聊天记录。


## 6. 开机和冒烟门禁

批量拍摄前先录3段不计入统计的小样：

1. 单人在`D→L→C`三个区域正常行走，20秒；
2. 两人在`L`区域正常对话，30秒；
3. 两人在`L`区域朗读一句虚构风险台词，30秒。

开始正式拍摄前必须确认：

- MP4可播放，分辨率、FPS和时长正确；
- 区域中心点落在正确多边形内；
- 轨迹适配器至少能输出区域或活动Observation；
- 行为追踪覆盖率硬门槛不低于0.35，目标不低于0.60；
- 两名演员的声音清晰，转写不是空文本；
- 风险台词转写允许存在同音字，但至少保留一项可归一化命中；
- 输出不包含绝对路径、真实姓名、设备序列号或凭证。

任何一项失败先修复机位、光照、区域或收音，再开始批量拍摄。

## 7. 心理趋势：12组、15段源视频

### 7.1 组合方式

P01、P02、P03每人完成4组：正常、活动下降、昼夜节律变化、下降后恢复。

| 场景组 | 使用视频 | 人工预期 |
|---|---|---|
| `M-Pxx-NORMAL` | `NORMAL` | 不产生心理风险Evidence |
| `M-Pxx-DECLINE` | `DECLINE` | 活动范围或区域转换下降 |
| `M-Pxx-RHYTHM` | `RHYTHM-DAY`+`RHYTHM-NIGHT` | 昼夜活动比例偏移 |
| `M-Pxx-RECOVERY` | `DECLINE`+`RECOVERY` | 黄色提示后恢复并解除 |

每名参与者实际拍5段，共15段；每段之间休息2分钟并恢复场地。

### 7.2 `NORMAL`：正常活动，150秒

目的：验证稳定的多区域活动和正常转换，不产生心理风险结论。

```text
0-10秒    空画面参考
10-25秒   参与者从D进入L
25-45秒   在L整理空白文件夹或坐下再站起
45-60秒   从L走到C
60-75秒   从C返回L
75-90秒   从L走到D
90-105秒  从D返回L
105-130秒 在L做轻微、自然的居家活动
130-145秒 从L走到C并停稳
145-150秒 保持
```

预期Observation：访问3个区域、至少5次有效转换、正常活动摘要。

禁止：夸张徘徊、快速往返、表演情绪低落或说出医疗结论。

### 7.3 `DECLINE`：活动下降，150秒

目的：验证单一区域、低转换的客观行为表现。

```text
0-10秒    空画面参考
10-25秒   参与者从D进入L
25-55秒   在L坐下或安静整理物品
55-85秒   在L站起、移动1-2步后停下，不跨区
85-120秒  继续停留在L，可进行轻微自然动作
120-135秒 在L坐下或站立保持
135-150秒 从L走向D并结束
```

预期Observation：主要停留在1个区域，区域转换明显少于`NORMAL`。

注意：单段视频本身不直接生成“多日活动下降”结论。算法只把这些客观量写入日汇总，再由模拟7日基线进行趋势验证。

### 7.4 `RHYTHM-DAY`：模拟日间低活动，120秒

```text
0-10秒    空画面参考
10-25秒   参与者进入L
25-100秒  在L安静停留，仅完成一次站起或取放物品
100-115秒 离开L进入D
115-120秒 空画面
```

场记必须填写`lighting=SIMULATED_DAY`。该标签表示实验脚本，不代表真实连续日间监测。

### 7.5 `RHYTHM-NIGHT`：模拟夜间活动增加，120秒

保持安全照度，不拍全黑画面。

```text
0-10秒    空画面参考
10-25秒   从D进入L
25-40秒   L到C
40-55秒   C回L
55-70秒   L到D
70-85秒   D回L
85-100秒  L到C再返回L
100-115秒 在L停稳
115-120秒 保持
```

场记填写`lighting=SIMULATED_NIGHT`。预期Observation为模拟夜间活动和转换明显高于`RHYTHM-DAY`。

### 7.6 `RECOVERY`：恢复正常活动，150秒

该段应在`DECLINE`之后拍摄，但两段都属于同日受控实验。

```text
0-10秒    空画面参考
10-25秒   从D进入L
25-45秒   在L完成自然活动
45-60秒   L到C
60-75秒   C回L
75-90秒   L到D
90-105秒  D回L
105-125秒 L到C再返回L
125-145秒 在L自然活动并停稳
145-150秒 保持
```

预期：在后台先提交下降趋势，再提交家属联系结果和恢复趋势，状态从`YELLOW/OPEN`进入`OBSERVING`并最终`RESOLVED`。

### 7.7 心理趋势日汇总说明

每个场景组另外生成一份脱敏JSON：前7日为模拟稳定基线，第8日对应当前场景；恢复组增加第9日恢复记录。

必须保存以下对应关系：

```text
视频轨迹输出 -> 当日行为Observation
人工场景标签 -> expected_evidence
模拟7日汇总 -> 多日趋势规则输入
家属反馈 -> family_contact_completed
恢复日汇总 -> trend_recovered
```

不得把15段录像描述成真实8天连续监测。

## 8. 诈骗核验：24段详细脚本

### 8.1 通用角色和动作

- `R`：居家人员，始终使用虚构身份，不展示真实手机内容。
- `V-A`：台账标记为已授权访客。
- `V-U`：台账标记为未登记访客。
- 每段开始先保留5秒空画面；访客从`D`进入`L`。
- “长停留”必须连续录够规则阈值，推荐有效停留130秒以上，不通过剪辑、循环或变速伪造。
- 台词可以自然改写，但不得改变人工真值或加入未登记的风险词。

### 8.2 `AN`：授权访客＋正常对话，6段，每段60秒

人工预期：授权匹配、短暂停留、无风险关键词；不生成橙色事件。

| clip_id | 角色 | 台词主题 | 必须避免 |
|---|---|---|---|
| `FRAUD-AN-01` | R+V-A | “我来送上次借的书，放在桌上。” | 转账、验证码、收益 |
| `FRAUD-AN-02` | R+V-A | “下周社区活动在周三，需要的话我再通知你。” | 真实社区名称和电话 |
| `FRAUD-AN-03` | R+V-A | “水杯和药盒我放在原来的位置。” | 真实疾病和药名 |
| `FRAUD-AN-04` | R+V-A | “天气凉了，记得关窗，我先回去了。” | 私人家庭信息 |
| `FRAUD-AN-05` | R+V-A | “这是普通维修预约单，你先留着，不需要付款。” | 真实公司名称 |
| `FRAUD-AN-06` | R+V-A | “我把活动照片带来了，我们一起看一下。” | 真实人物照片 |

统一时间轴：

```text
0-5秒    空画面
5-15秒   V-A从D进入L，R迎接
15-45秒  按表中主题正常交流
45-55秒  V-A离开L进入D
55-60秒  空画面
```

### 8.3 `UB`：未登记访客＋短暂停留，4段，每段45秒

人工预期：允许生成`unauthorized_visitor`，但不得进入橙色。

| clip_id | 台词 |
|---|---|
| `FRAUD-UB-01` | V-U：“您好，我可能走错门了。” R：“这里不是您要找的地方。” |
| `FRAUD-UB-02` | V-U：“请问这栋楼的出口在哪里？” R：“从走廊向右走。” |
| `FRAUD-UB-03` | V-U：“我来确认一个普通预约。” R：“我没有预约，请先联系家属。” |
| `FRAUD-UB-04` | V-U：“请问这里有人需要送水吗？” R：“没有，谢谢。” |

统一时间轴：

```text
0-5秒    空画面
5-15秒   V-U从D进入L边缘
15-30秒  完成简短问答，不靠近R
30-40秒  V-U主动离开
40-45秒  空画面
```

### 8.4 `AK`：授权访客＋风险词，4段，每段75秒

这是关键词困难负样本。允许产生低置信`fraud_keyword`，但因访客授权且无长停留，不得进入橙色。

| clip_id | 良性语境台词 |

| `FRAUD-AK-01` | “家里转账之前一定要先和你确认，不能着急操作。” |

| `FRAUD-AK-03` | “正规的投资不会承诺保证收益，听到这种话要警惕。” |
| `FRAUD-AK-04` | “新闻里说有人冒充客服要求马上付款，我们不要相信。” |

统一时间轴：

```text
0-5秒    空画面
5-15秒   V-A进入L
15-55秒  自然完成台词，可重复一次关键句保证收音清楚
55-65秒  R回答：“知道了，我会先联系家里人核实。”

```

人工预期中不得把`fraud_keyword`列为错误；错误条件是进入橙色或输出“已确认诈骗”。

### 8.5 `UD`：未登记访客＋长停留、无风险词，4段，每段150秒

这是停留困难负样本。允许生成`unauthorized_visitor`和`unusual_dwell_time`，但无`fraud_keyword`时不得进入橙色。

| clip_id | 无风险主题 |
|---|---|
| `FRAUD-UD-01` | 天气和公共活动 |
| `FRAUD-UD-02` | 普通家电使用说明 |
| `FRAUD-UD-03` | 找错地址后等待确认 |
| `FRAUD-UD-04` | 普通兴趣爱好交流 |

统一时间轴：

```text
0-5秒     空画面

```

不得用静止照片、循环视频或后期复制帧制造长停留。

### 8.6 `CO`：未登记访客＋长停留＋风险组合词，6段，每段180秒

人工预期：三类Evidence齐全，进入`ORANGE/INTERVENING`并出现家属核验建议。系统仍不得输出“已确认诈骗”。

| clip_id | 虚构场景 | 必须包含的台词 |
|---|---|---|
| `FRAUD-CO-01` | 虚构养老投资 | “这个项目保证收益，今天马上办理，需要先转一笔虚构定金。” |

| `FRAUD-CO-03` | 虚构客服处理 | “账户需要立即处理，不要挂断，请按我的提示马上操作。” |
| `FRAUD-CO-04` | 虚构亲友求助 | “情况很急，先转一笔虚构款项，不要先联系其他家人。” |
| `FRAUD-CO-05` | 虚构中奖返现 | “先支付虚构手续费，之后会返还更高金额。” |
| `FRAUD-CO-06` | 虚构上门服务 | “今天预付才能享受优惠，保证不会有任何损失。” |

统一时间轴：

```text
0-5秒      空画面
5-15秒     V-U从D进入L
15-120秒   进行普通寒暄、展示空白文件夹并持续停留
120-155秒  自然说出表中风险组合词，不展示真实账户或支付页面
```

家属核验属于页面和后台操作，不需要额外拍摄摄像机视频，但最终演示应录制屏幕操作。

## 11. 客观补拍条件

出现以下任一情况必须补拍，不能通过改标签解决：

- 文件损坏、时长不足、编码不可读；
- 人物关键动作持续出画或区域坐标明显错误；
- 长停留未达到冻结阈值；
- 风险台词遗漏、严重说错或录音不可理解；
- 非风险场景误说风险词；
- 未授权人员、真实账号或私人信息入镜；
- 摄像机移动、云台跟随或分辨率/FPS发生变化；
- 现场发生真实冲突、不适或安全事件。

以下情况不得作为补拍理由：

- 算法漏检或误报；
- 输出没有达到团队期待；
- 困难负样本触发了错误结果。

这些失败必须保留并计入最终工程场景统计。

### 12.1 当天完成

### 12.2 算法批处理

心理素材：

```text
MP4 -> TRAJECTORY -> 区域/转换Observation
Observation -> 脱敏日汇总
7日模拟基线+当前日 -> MENTAL Evidence
家属联系+恢复日 -> trend_recovered -> RESOLVED
```

诈骗素材：

```text
MP4 -> TRAJECTORY -> 访客/停留Observation和Evidence

多证据组合 -> FRAUD RiskEvent
家属核验 -> identity_verified/false_alarm_confirmed -> RESOLVED
```

每个场景使用独立`resident_id`或隔离数据库，防止前一个事件影响后一个场景。相同场景运行两遍，第二遍验证Observation、Evidence和RiskEvent不重复创建。
