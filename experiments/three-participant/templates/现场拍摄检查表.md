# 三参与者现场拍摄检查表

## 每个拍摄日开始前

- [ ] C6c型号、分辨率、帧率与前一拍摄日一致。
- [ ] 云台追踪、自动变焦和巡航已关闭。
- [ ] 摄像机回到`C6c-pos01`地面标记，镜头高度约1.0-1.3米。
- [ ] 3-5米路线、椅子位置和停止点已标记。
- [ ] 椅脚防滑，路线无电线、湿滑、杂物或卷边地毯。
- [ ] 人物全身占画面高度约55%-80%，头、肩、髋、膝、踝和脚清晰。
- [ ] 衣物与背景、裤子与地面有明显对比。
- [ ] 保护人员位于镜头外且伸手可及。
- [ ] 授权记录编号已填写，画面中没有证件、门牌或私人屏幕。

## 三段小样门禁

每名参与者先拍正常左到右、正常右到左、慢速小步各1段。批量拍摄前确认：

- [ ] OpenCV可以读取视频，时长和真实FPS正确。
- [ ] 33点关键点CSV不为空，成功帧覆盖0-32号关键点。
- [ ] 肩、髋、踝没有持续跳到背景，双脚未出画。
- [ ] 正常片段`valid_frame_ratio >= 0.85`。
- [ ] 正常片段`mean_core_visibility >= 0.80`。

## 每段录制后

- [ ] 文件可播放，文件名、参与者、场景和重复序号正确。
- [ ] 机位、焦距和椅子未移动。
- [ ] 动作区间和人工真值已立即记录，未查看算法结果后反改标签。
- [ ] `source_mode=RECORDED_REPLAY`且`simulated=true`。
- [ ] 无安全事件；如有，已标记`ABORTED`并写明原因。
- [ ] 原始文件只保存在`private/`或其他受控目录。

## 黄金115秒片段

```text
0-8秒    自然坐姿
10-12秒  快速但可控起身
12-22秒  受控躯干摇晃
22-30秒  缓慢坐回并调整稳定
30-45秒  连续稳定15秒
45-105秒 继续观察60秒
105-115秒 保持稳定并留编码缓冲
```

- [ ] 观察期内未再次快速起身、摇晃、出画或遮挡。
- [ ] 片段连续完整，未剪除失败区间冒充成功。
