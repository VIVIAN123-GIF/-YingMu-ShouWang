# v1.5 探索性重分析

本目录用于不能补拍条件下的软件整改审计，不是新的正式盲测。输入仍为已经在 v1.4 正式运行中查看过的29段素材，人工标签、媒体哈希和 v1.4 正式输出均保持不变。

## 固定边界

- 结果分类必须为 `EXPLORATORY_REANALYSIS`。
- 不覆盖 `supplemental-validation-v1.4` 或 P03 的任何文件。
- 不因结果修改原标签、删除失败片段或选择性重跑。
- 单段视频只构成一个活动窗口，可以报告趋势候选 Evidence，不能冒充需要两个独立窗口的持续趋势告警。
- 没有可观测的第二即时信号族时不生成 ORANGE。
- QG05 继续单独报告，不能用旧黄金闭环替换。

## v1.5 整改

- 个人速度比较增加 `WALK`、`POST_RISE_LOCOMOTION`、`RISE_ONLY` 和 `STATIC_OR_UNKNOWN` 活动上下文；缺少匹配基线时保守降级，不跨上下文回退。
- 步态不对称改用骨盆相对坐标中的左右脚周期摆幅，至少需要两个完整双侧周期。
- 人体质量增加人体 ROI 亮度中位数、P10、对比度和“姿态冻结但画面仍变化”的遮挡代理。
- 即时 ORANGE 仍要求同一坐站后窗口中至少两个独立信号族，不降低该安全约束。

探索性结果只用于解释软件修复及剩余限制，不能替换 v1.4 正式指标。
