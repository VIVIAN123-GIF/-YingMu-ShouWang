# 个体化多源跌倒前置预警 v1.3-min

文档状态：2026-08-31 开发冻结前的工程实现与验收边界。

## 1. 定位与比赛方案响应

`ruleset-v1.2` 继续负责“起身后即时不稳事件”和确定性 RiskEvent 裁决；`ruleset-v1.3-min` 是独立的前置预警层。后者把人体姿态、个人基线、场景环境和人境交互汇总为工程风险指数，不输出跌倒概率，也不替代临床评估。

相较只依赖快速起身与二维躯干摆角的原型，本版本增加：

- 躯干、骨盆横移、支撑面变化、补偿步等多信号人体证据；
- 8 秒即时、30 秒短时、180 秒趋势三个尺度；
- 基于中位数和 MAD 的个人偏离，以及 `INSUFFICIENT/PROVISIONAL/STABLE` 冷启动权重；
- 归一化 `HIGH_RISK/SUPPORT/OBSTACLE/SAFE` 场景多边形；
- 人体与环境同窗时才计算交互风险，环境证据不能单独创建跌倒事件；
- 对遮挡、低照、跟踪不足、错误机位和无人体证据输出 `PARTIAL/INSUFFICIENT`，不伪装为 GREEN；
- 干预前后快照、恢复结果和来源标识的可审计关联。

## 2. 数据流与职责边界

```text
Asset
  -> 一次 MediaPipe 姿态序列（仅进程内短期缓存）
  -> GAIT + TRAJECTORY
  -> Observation + Evidence
  -> ForewarningSnapshot（v1.3-min）
  -> RiskEvent 确定性裁决（v1.2）
  -> RuleTrace + AgentExplanationJob
  -> InterventionResult + POST_INTERVENTION Snapshot
```

原始关键点和画面不进入数据库。智能体只解释证据、置信度、降级原因和建议动作，不能修改风险等级，也不能称为临床诊断或未来跌倒概率。

## 3. 指数与质量门控

四路分量为 `human_risk`、`personal_deviation`、`environment_risk` 和 `interaction_risk`。个人偏离按以下稳健公式计算并截断到 `0..1`：

```text
z = |current - median| / max(1.4826 * MAD, 10% * |median|, epsilon)
```

基线不足时个人分量不参与。观察等级为 `<0.4 GREEN`、`0.4-0.7 YELLOW`、`>=0.7 ORANGE`；数据不足单列 `UNKNOWN`。这些等级只描述快照，不直接创建 RiskEvent。

只有参与者、授权记录、采集日期、机位和有效性字段完整的正常素材才能进入个人基线。少于三个有效日期时维持 `INSUFFICIENT`。

## 4. 接口

```text
GET /api/v1/residents/{id}/forewarning/latest
GET /api/v1/residents/{id}/forewarning?from=&to=&limit=
GET /api/v1/events/{id}/forewarning
GET /api/v1/scene-calibrations/{id}
```

`RiskEvaluateResponse.forewarning_snapshot` 为可选字段，旧调用保持兼容。`ResidentBaselineResponse.pre_fall_summary` 由最新快照生成兼容视图。场景配置通过 `scripts/install_scene_calibration.py` 校验后安装到私有目录，不开放无鉴权写接口。

## 5. 双轨验收结论

`RECORDED_REPLAY/simulated=true` 已使用授权真实录制像素完成一次匿名回放。GAIT 与 TRAJECTORY 均实际运行，系统保存 Observation、Evidence、ForewarningSnapshot 和 RuleTrace。该片段因人体证据、个人基线和场景上下文不足，正确返回 `INSUFFICIENT/LOW/UNKNOWN`，未创建 RiskEvent。跨表引用完整性检查通过。

本次素材没有触发合格 ORANGE，因此没有把这次回放写成事件、智能体、干预和恢复正向闭环。后半链由确定性自动化测试覆盖，仍需补充一段按新脚本采集、授权且标注完整的正样本，才能形成真实录制像素的正向闭环证据。

`LIVE_DEVICE/simulated=false` 的历史采集与 Worker 链路已有独立记录，但 v1.3-min 的实机双适配器与保守裁决尚待新一轮现场验收。实机结果不得与回放结果混写。
