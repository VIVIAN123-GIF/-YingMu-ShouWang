## 测试结果汇总

| 测试场景 | HTTP状态码 | 萤石业务code | 返回提示msg | 结论 |
| ---- | ---- | ---- | ---- | ---- |
| 正常鉴权：正确AppKey + 正确AppSecret | 200 | 200 | 操作成功! | 鉴权链路正常，可以获取accessToken，token有效时长由expireTime控制 |
| 异常：AppKey填写错误 | 200 | 10017 | appKey不存在 | 密钥标识错误，开发代码需要捕获该错误 |

| 异常：appSecret传入空字符串 | 200 | 10001 | appSecret不能为空! | 空字符串等同于缺失，参数合法性校验失败 |
| 异常：请求彻底缺失appKey参数 | 200 | 10001 | appKey不能为空! | 入参缺失，参数合法性校验失败 |
| 异常：请求彻底缺失appSecret参数 | 200 | 10001 | appSecret不能为空! | 入参缺失，参数合法性校验失败 |

## 开发备注
1. accessToken 需要业务代码缓存，不要每次请求业务接口重复调用鉴权；
2. 所有萤石接口不要依靠HTTP状态码判断成功与否，必须解析返回JSON内的code字段；
3. 后续调用视频、语音接口时，如果返回token失效错误，重新执行鉴权刷新token；
4. 空字符串与不传参数返回相同错误码，代码校验时统一处理即可。
