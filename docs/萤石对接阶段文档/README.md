### 阶段3：FastAPI萤石Mock模拟服务（完整可运行）
1. 交付文件夹：`ys7_mock`

    - requirements.txt：补齐全部依赖，包含python-multipart，解决表单参数启动报错

## 五、启动&使用指引
1. 阶段一鉴权自测：使用Postman发送x-www-form-urlencoded表单请求萤石真实鉴权地址，对照测试文档记录报文
2. 阶段三Mock服务启动
```bash
cd ys7_mock
pip install -r requirements.txt
python main.py
```
访问 `http://127.0.0.1:8001/docs` 在线调试全部模拟接口
3. 后端对接Mock：修改backend/config.py `ENV = "mock"`
4. 硬件到货切换真实接口：修改backend/config.py `ENV = "real"`，无需启动Mock服务
