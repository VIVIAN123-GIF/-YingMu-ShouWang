## 安全规则

- 文档中的AppKey、AppSecret、AccessToken、设备序列号和家庭网络信息必须脱敏；
- 不在日志中记录AccessToken或Secret，只记录请求ID、脱敏设备别名、错误码、错误信息和重试次数；
- Token生命周期以接口返回的`expireTime`为准，不在代码或材料中写死固定天数；
- 真实凭据仅通过本地环境变量或受控密钥管理注入，不进入代码库、飞书正文或演示材料。
