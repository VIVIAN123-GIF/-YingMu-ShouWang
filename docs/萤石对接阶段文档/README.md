## 当前能力边界

- 真实 Webhook、告警入库和算法任务调度已经实机验证；
- 设备主、子码流均固定为标准 H.264；HTTP-FLV 是当前现场主路径，HLS 是兼容路径；
- HTTP-FLV/HLS 均已通过 15 秒真实连续画面验证，真实告警任务仍需补端到端稳定性测试；
- 历史 TRAJECTORY/GAIT 结果的输入是 H.265 不兼容提示片，不作为真实画面算法验收证据；
- GAIT 对真实连续画面的算法业务验收尚未完成；
- 萤石服务端语音和双向对讲仍不得写成已验证能力；
- 临时通道地址会变化，不属于永久部署能力。

## 安全规则

- 文档中的 AppKey、AppSecret、AccessToken、设备序列号和家庭网络信息必须脱敏；
- 不在日志中记录 AccessToken、Secret 或临时播放 URL，只记录请求 ID、脱敏设备别名、
  错误码和重试次数；
- Token 生命周期以接口返回的 `expireTime` 为准，不在代码或材料中写死固定天数；
- 真实凭据仅通过本地环境变量或受控密钥管理注入，不进入代码库、群聊正文或演示材料；
- 私有媒体保存在仓库和同步盘之外，并受授权与保留期限控制。
