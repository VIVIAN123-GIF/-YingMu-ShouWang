## 使用约定

- 新的长期有效技术规范放在本目录；文件名使用 `主题.md` 或 `YYYY-MM-DD_主题.md`。
- 一次性运行输出、截图、日志和验收原始结果放在 `artifacts/` 或 `deliverables/`，不要放入本目录。
- 文档移动前必须同步更新引用链接；因此现有文件暂不批量改名或迁移。
- 阶段性能力矩阵保留历史测试结论；判断当前可用能力时先查阅最新日期的联调结论文档。
