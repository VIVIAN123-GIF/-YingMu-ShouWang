# 正向双片段与最终机位现场执行检查表

## 开始前

- [ ] 授权记录有效，参与者匿名编号和保留期限已填写。
- [ ] 摄像机位置、俯仰角、焦距、分辨率和照明已冻结；云台跟踪、巡航和自动变焦已关闭。
- [ ] `camera_position_id`、`scene_config_id` 和 `location=living_room` 已记录。
- [ ] 摄像机和主要家具位置已有物理标记；拍摄两段之间不得移动。
- [ ] 头、肩、髋、膝、踝和双脚完整入镜，衣物与背景对比清晰。
- [ ] 椅子稳定防滑，路线无电线、湿滑、杂物和卷边地毯。
- [ ] 安全员在画外伸手可及，已约定立即停止口令。
- [ ] 规则阈值和拍摄动作已在运行算法前冻结。

## 风险段

- [ ] 先保留至少 3 秒稳定坐姿，再完成自然坐站转换。
- [ ] 起身完成后的 5 秒窗口内只执行预先约定的受控动作。
- [ ] 不追求真实失衡；动作超过安全员判断范围立即停止。
- [ ] 全程保持正面或前侧固定朝向，不持续转身或自然走离画面。
- [ ] 片段结束后立即记录坐站转换和动作窗口时间，不查看算法结果。

## 恢复段

- [ ] 与风险段为同一参与者、同一机位、同一画幅和同一场景配置。
- [ ] 参与者从片段开始即自然稳定站立，连续录制建议 18-20 秒。
- [ ] 不要求再次坐站转换，不加入摆动、补偿步或干预动作。
- [ ] 稳定时长和最大躯干角由两名标注员独立记录。

## 每段结束后

- [ ] 文件可播放，技术参数和片段角色正确。
- [ ] 填写带时区拍摄时间、SHA-256、授权号、保留期限和有效性。
- [ ] 两名标注员在算法运行前完成标签；分歧先仲裁再冻结。
- [ ] 安全事件、遮挡、出画或机位变化时标为 `ABORTED/REJECTED`，不得剪辑成通过片段。
- [ ] 原始文件只保存到仓库和 OneDrive 外的受控目录。
