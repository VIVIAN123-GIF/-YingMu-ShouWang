# 故事动作—系统交互矩阵

## 一、统一交互链路

> Evidence输入 → 查询个人记忆 → 状态机判断 → 生成RiskEvent → 调用萤石工具 → 收集InterventionResult → 风险回落

所有场景使用同一套老人档案、个人记忆、状态机、事件时间轴和家属端。心理和诈骗只增加Evidence适配器。

## 二、第零幕：安装与冷启动

| 项目 | 冻结内容 |
|---|---|
| 触发 | 女儿首次为张爷爷安装设备 |
| 智能体输入 | 基础画像、独居情况、既往跌倒、关节问题、作息、授权和通知偏好 |
| 系统动作 | 创建老人档案、隐私区域、通知等级、家属联系人和语音资源 |
| 老人动作 | 确认隐私范围和是否接受语音提醒 |
| 家属动作 | 填写3分钟问卷、录制提醒、完成授权 |
| 反馈 | 设备在线、语音测试成功、授权保存成功 |
| 退出 | 档案和设备配置完成，进入基线建立 |
| 降级方案 | 语音播放接口未确认时，使用本地音箱或前端模拟播放，并明确标注 |
| 对应页面 | 新建老人、问卷、隐私设置、语音录制、设备检测 |

## 三、第一幕：无感监测与个人基线

| 项目 | 冻结内容 |
|---|---|
| 触发 | 设备配置完成并开始采集 |
| 智能体输入 | 起身、姿态、活动轨迹、照度、区域和数据质量Evidence |
| 系统动作 | 建立短时30秒、中时24小时、长时7天以上个人记忆 |
| 老人动作 | 无需主动操作 |
| 家属动作 | 只查看基线建立进度和设备状态 |
| 反馈 | 基线有效样本数、数据质量、正常范围 |
| 退出 | 形成初步个人基线并持续滚动更新 |
| 降级方案 | 真实多日数据不足时使用标注为“模拟回放”的多日特征序列 |
| 对应页面 | 基线进度、趋势曲线、活动热力图、设备状态 |

## 四、第二幕：心理趋势与家属关怀

| 项目 | 冻结内容 |
|---|---|
| 触发 | 活动范围、房间转换和昼夜节律连续偏离个人基线 |
| 智能体输入 | activity_range_decline、room_transition_decline、day_night_rhythm_change、family_concern |
| 系统动作 | 生成黄色RiskEvent，进入周报并给出“联系老人”建议 |
| 老人动作 | 在沟通中自愿表达近况；自行决定是否参加简短筛查 |
| 家属动作 | 查看趋势、联系老人、填写关怀反馈 |
| 反馈 | 老人自述、家属反馈、自愿筛查结果、后续活动趋势 |
| 退出 | 趋势停止恶化且完成关怀反馈；持续异常则保留黄色并建议专业评估 |
| 降级方案 | 不做语音情绪诊断；活动数据不足时展示模拟趋势并标明 |
| 对应页面 | 黄色周报、趋势证据、关怀确认、自愿筛查、专业建议 |

心理场景一期最高自动等级为黄色，不输出抑郁症、认知症或MCR诊断。

## 五、第三幕：陌生来访与身份核验

| 项目 | 冻结内容 |
|---|---|
| 触发 | 非授权访客长时间停留并出现高风险交互特征 |
| 智能体输入 | unauthorized_visitor、unusual_dwell_time、fraud_keyword、unusual_pacing |
| 系统动作 | 聚合多证据，生成黄色或橙色RiskEvent和身份核验卡 |
| 老人动作 | 不被公开指责或强行中断，可选择先与家属确认 |
| 家属动作 | 查看证据卡、一键联系老人、提交身份核验结果 |
| 反馈 | verified、visitor_left、false_alarm或escalated |
| 退出 | 身份确认或访客离开，且无新风险证据 |
| 降级方案 | 访客识别未完成时使用人工标记的访客事件；Whisper延迟高时使用预先转写文本 |
| 对应页面 | 访客事件、停留时间、关键词摘要、身份核验、回落结果 |

单个关键词不触发橙色，不读取陌生电话号码，不判断真实转账。

## 六、第四幕：黄金半分钟跌倒干预

| 项目 | 冻结内容 |
|---|---|
| 触发 | 30秒内出现快速起身、躯干摇晃等两类独立高风险Evidence |
| 智能体输入 | rapid_rise、trunk_sway、low_illumination、high_risk_zone_entry和个人基线 |
| 系统动作 | 生成橙色RiskEvent，调用语音/推送，进入干预后观察 |
| 老人动作 | 根据短句提醒先坐稳或扶稳 |
| 家属动作 | 查看事件原因和处置结果；持续危险时接管 |
| 反馈 | posture_recovered、tool_delivery_status、resident_response |
| 退出 | 姿态恢复、连续15秒无新风险并完成至少60秒观察 |
| 降级方案 | 萤石语音不可用时使用本地模拟工具；实时姿态未完成时输入模拟Evidence |
| 对应页面 | 证据链、风险水位、工具状态、观察期、回落摘要 |

## 七、统一适老化规则

- 老人侧一次只给一个动作；
- 黄色风险原则上不在老人侧报警；
- 不使用“你要跌倒了”“你被骗了”“你得了抑郁症”等标签；
- 家属看到具体证据、建议动作和处置结果，不只看到风险分；
- 工具调用失败必须可见，不把“请求已发出”当作“干预成功”；
- 原始视频默认不长期保存；
- 卫生间仅监测门口，不采集内部画面。
