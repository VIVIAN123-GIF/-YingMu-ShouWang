# “萤目守望”交互方法初步调研——PPT逐页稿

## 第1页：封面

标题：萤目守望——交互方法初步调研  
副标题：从“完整故事”走向“可运行产品”  
页脚：吉林大学团队｜2026.07.23｜技术与交互讨论稿

讲述重点：

> 当前故事和总体方案已经冻结。本轮不再扩写故事，而是逐幕回答触发什么、系统做什么、老人和家属做什么、如何确认风险解除。

## 第2页：两条核心交互原则

内容：

- 低风险不打扰：系统先学习老人平常安全的样子，单次低置信度异常只记录；
- 关键时刻只给一个动作：例如“爸，先坐稳，慢慢起身”；
- 每次干预必须复核：消息送达不等于风险解除。

讲述重点：

> 适老化不是把按钮做大，而是减少老人必须做的事情，控制提醒次数，并在真正危险时给出清晰动作。

## 第3页：四类参与者，一个闭环

角色：

- 老人：被低打扰守护，必要时完成一个简单动作；
- 异地子女：接收证据卡、完成关怀或身份核验；
- 智能体：管理个人记忆、状态机和工具调用；
- 萤石设备：提供视频、语音/对讲和消息能力。

讲述重点：

> 智能体不是聊天机器人，而是将Evidence、个人记忆、状态机和萤石工具组织成观察—判断—干预—复核闭环。

## 第4页：100天用户旅程

时间轴：

- 第0天：问卷、授权、家属语音；
- 第1—70天：无感学习个人基线；
- 第71—90天：生活半径缩小，触发黄色关怀；
- 第96天：陌生来访，触发身份核验；
- 第100天：快速起身和摇晃，完成黄金半分钟干预。

讲述重点：

> 跌倒是核心验证任务。心理和诈骗只是将不同Evidence接入同一套记忆和状态机。

## 第5页：第零幕——安装与冷启动

交互流程：

> 女儿填写问卷 → 老人确认隐私和提醒 → 录制家属语音 → 设备/消息测试 → 进入基线建立

页面：

- 老人档案；
- 隐私区域；
- 通知等级；
- 家属语音；
- 设备检测。

待验证：

- 萤石是否支持程序主动播放预录语音或TTS；
- 不支持时使用何种本地替代方案。

## 第6页：第一幕——无感监测与个人基线

三时标记忆：

- 短时30秒：临近危险；
- 中时24小时：当日风险状态；
- 长时7天以上：个人行为与步态基线。

交互：

- 老人不操作；
- 家属只看“基线建立中”和设备状态；
- 原始视频默认不长期保存。

待验证：

- 稳健基线使用MAD、EWMA还是其他方法；
- 公开数据与自采数据如何分工。

## 第7页：第二幕——心理趋势与家属关怀

交互链：

> 活动范围和作息持续偏离 → 黄色周报 → 女儿联系 → 老人自述 → 自愿筛查/专业建议 → 趋势与反馈复核

原则：

- 系统只发现行为变化；
- 心理信息来自老人自述和人工确认；
- 一期最高自动等级为黄色；
- 不诊断抑郁症、认知症或MCR。

待验证：

- 哪些行为趋势有足够研究依据；
- 黄色提醒频率和持续时间。

## 第8页：第三幕——陌生来访与身份核验

交互链：

> 非授权访客＋异常停留＋高风险关键词 → 统一Evidence → 黄色/橙色事件 → 家属核验卡 → 身份确认 → 回落

原则：

- 单个关键词不报警；
- 不公开指责访客；
- 不读取陌生号码，不判断真实转账；
- 家属是最终身份核验者。

待验证：

- 访客识别最低实现方式；
- Whisper模型、延迟和隐私处理。

## 第9页：第四幕——黄金半分钟

时间轴：

- 0秒：快速起身；
- 1秒：检测躯干摇晃；
- 2秒：个人基线与低照度证据融合；
- 3秒：触发橙色并调用语音；
- 15秒：识别重新坐稳；
- 60秒：观察期完成，事件回落。

讲述重点：

> 这是唯一必须实现完整、实验最严格的核心闭环。上述秒数是交互目标，不是当前实测结果。

## 第10页：智能体交互闭环

固定数据流：

> Evidence → 个人记忆 → 规则状态机 → RiskEvent → 萤石工具 → InterventionResult → 回落

智能体可以：

- 查询记忆；
- 调用确定性状态机；
- 选择批准的干预策略；
- 调用工具；
- 生成解释和周报。

智能体不可以：

- 绕过状态机；
- 医学诊断；
- 自动修改阈值；
- 自动拨打120。

## 第11页：核心页面低保真

三个页面：

1. 首页安全水位：当前等级、今日状态、设备在线；
2. 事件详情：证据链、系统动作、工具状态、回落过程；
3. 周报与核验：长期趋势、关怀确认、访客身份核验。

交互要求：

- 一个老人档案；
- 一个事件时间轴；
- 一个风险状态机；
- 三方向用Evidence标签区分，不做三个后台。
