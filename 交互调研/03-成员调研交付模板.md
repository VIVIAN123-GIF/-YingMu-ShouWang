# 成员调研交付模板

## 一、统一要求

调研不是资料摘抄。每位技术成员必须提交：

- 一页可行性结论；
- 一个可运行最小Demo或明确失败记录；
- 至少3条符合统一接口的Evidence样例；
- 输入、输出和依赖；
- 数据需求；
- 主要风险；
- 降级方案；
- 7月31日前能完成的内容。

## 四、张薇评审表

| 检查项 | 通过标准 |
|---|---|
| 有明确结论 | 不是“还需继续研究” |
| 有输入输出 | 可以接入统一接口 |
| 有Demo或失败日志 | 可复现 |
| 有Evidence样例 | 字段符合Freeze v1.0 |
| 有数据需求 | 样本和标注明确 |
| 有降级方案 | 失败不阻塞模拟闭环 |
| 有工期 | 明确到日期 |
| 不越界 | 不独立预警、不医学诊断 |
