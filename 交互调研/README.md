## 使用原则

- 当前解决方案与故事结构停止大改；
- PPT只说明如何把故事变成产品，不重复完整讲故事；
- 所有尚未完成的算法、接口和性能结论标记为“待验证”；
- 技术成员必须提供可行性结论、最小Demo、Evidence样例和降级方案；
- 研究生指导不阻塞7月31日模拟闭环；
- 实际开发继续遵循《冻结方案》中的统一接口和风险状态机。
- 当前唯一一台萤石C6c尚未到货且到货后由张薇保管；到货前全部调研和原型使用Mock、公开数据或离线素材，不等待实机。
- 跌倒最终使用实机验证；心理和诈骗使用同一设备集中拍摄的模拟实验回放，并在页面和材料中明确标注。
- 取流、抓图、云台、消息、语音/对讲和RTSP等具体能力在实机调用前统一标记为“待核验”。
- 智能体安全主链使用确定性规则状态机；大模型只接收脱敏结构化事实并生成解释或报告，模型失败不得阻塞主闭环。
- 智能体专项技术问题优先使用[7月25日技术交互会会议材料](./07-7月25日技术交互会会议材料.md)，会议必须形成推荐方法、来源、时间和降级方案。
