# C6c步态模块与智能体闭环详细拍摄脚本

版本：v1.0

制定日期：2026-08-03

适用截止：2026-08-07阶段验收

测试者：健康成年团队成员，匿名代号统一使用`P01`

本脚本合并以下两类需求：

1. 赵勇步态模块需要的连续行走、相对步速、步幅不对称、躯干摇晃和质量降级视频；
2. 智能体和后端需要的个人基线、快速起身组合、15秒恢复、60秒观察和事件闭环视频。

异常动作不由老人完成，不做真实跌倒、危险跛行或快速失控转身。

## 一、现有三段视频能做什么

| 现有素材 | 保留用途 | 不能替代的内容 |

| 19.13秒快速起身单例 | R-FALL-01快速起身单独保持GREEN | 只有1条重复，不能作为正常基线或连续步态测试 |
| 20.53秒稳定不足15秒 | 恢复不足15秒仍为INTERVENING | 没有完整起身链路，也不适合步幅基线 |

三段素材均为坐站场景，椅子会遮挡腿部，不能证明`step_speed`、`step_length_asymmetry_ratio`或至少4个完整步态周期。

## 三、拍摄前场地布置

### 1. 摄像机

- 使用同一台C6c，关闭云台自动追踪、自动变焦和巡航；
- 8月7日前保持现有实机口径`1280×720、15 fps`，不要在同一批基线中途修改分辨率或帧率；
- 后续适配必须读取视频真实fps和时间戳，不得把15 fps按30 fps解释；
- 主机位固定为侧前方30°—45°；
- 镜头高度约1.0—1.3米，向下俯角不超过15°；
- 摄像机距行走路线中心约3—5米，以人物全身占画面高度55%—80%为准；
- 在地面标记三脚架/摄像机投影位置和朝向，三日内不能移动。

### 2. 路线与椅子

- 用胶带标出3—5米横向路线、左起点、右终点和停止点；
- 路线尽量平行画面横轴；
- 椅子放在路线一端之外的固定标记处，不遮挡主要行走路线；
- 椅脚做防滑固定，椅背朝向应让双肩、双髋、双脚均可见；
- 地面无电线、地毯卷边、杂物或湿滑区域。

### 3. 人物和光照

- 画面只出现P01一名主测试者；保护人员站在镜头外、伸手可及的位置；
- 上衣与背景有明显对比，裤子与地面有明显对比；
- 不穿长裙、拖地衣物或遮住脚踝的宽大裤脚；
- 不逆光，双腿和鞋底接触地面位置清晰；
- 关闭电视，移走镜面反光、证件、门牌和私人屏幕内容；
- 录制期间不说私人信息，音频不是本次验收必需。

## 五、连续行走视频统一结构

除另有说明外，每条15秒：

| 时间 | 动作 |
|---:|---|
| 0–2秒 | P01全身入画，在起点自然站立，双脚均清晰可见 |
| 2–12秒 | 按指定场景连续横向行走8—12步，至少4个完整步态周期 |
| 12–15秒 | 在终点停下，自然稳定站立，不立刻出画 |

人物不能主要朝镜头走来或背离镜头。每条结束后停止录制，重新回到起点再开始下一条，避免一个长文件难以分段和标注。

## 六、步态P0逐场景脚本

### N01：正常步行，左→右，5条

文件名：

```text
20260803_P01_GAIT_N01_NORMAL_L2R_45DEG_NORMAL_15FPS_01.mp4
...
20260803_P01_GAIT_N01_NORMAL_L2R_45DEG_NORMAL_15FPS_05.mp4
```

动作：按平时自然速度直线行走，不刻意迈大步、不看脚、不摆拍摇晃。预期为高有效帧率、低风险偏离，用作个人正常步态重复性检查。

### N02：正常步行，右→左，5条

与N01完全相同，只改变方向。文件中的方向必须写`R2L`。N01和N02之间不得移动摄像机或改变焦距。

### S01：慢速小步，3条

统一15秒结构。2–12秒期间以明显慢于个人正常速度的小步前进，但保持平衡，不拖脚、不突然停顿。预期`step_speed`相对N01/N02下降。

文件动作码：`S01_SLOW_SMALL_STEP`。

### A01：安全模拟一侧步幅变小，3条

统一15秒结构。选择固定一侧，例如右脚；右脚每步明显比左脚短，但双脚正常抬起和落地，不做疼痛状跛行，不锁膝，不失去平衡。三条必须使用同一侧。

预期`step_length_asymmetry_ratio`上升。清单备注填写`shorter_step_side=RIGHT`。

### W01：行走时躯干左右摇摆，3条

统一15秒结构。保持慢到正常的安全速度，双脚正常行走，上身做清晰但幅度可控的左右摆动；不闭眼、不后仰、不做濒临跌倒动作。

预期躯干角度变化和摇摆相关指标上升。保护人员沿路线外侧跟随但不得入镜。

### C01：行走—停步—继续，3条

| 时间 | 动作 |
|---:|---|
| 0–2秒 | 起点稳定站立 |
| 2–6秒 | 正常行走约4—5步 |
| 6–8秒 | 在路线中部完全停住，保持直立 |
| 8–13秒 | 继续正常行走至终点 |
| 13–15秒 | 稳定站立 |

预期系统能解释短暂停顿，不应直接把停顿当作跟踪丢失。

### T01：缓慢转身，3条

| 时间 | 动作 |
|---:|---|
| 0–2秒 | 起点稳定站立 |
| 2–7秒 | 正常行走到中部标记 |
| 7–10秒 | 分2—3小步缓慢转身，不原地快速旋转 |
| 10–14秒 | 向原方向返回 |
| 14–16秒 | 稳定站立 |

该组只用于边界和误报分析，不与直线正常基线混算。

### Q01：脚踝短暂遮挡，3条

在路线中间放置稳定、无尖角的矮家具，使双脚踝在2—4秒内被遮挡，但上身仍可见。摄像机不动，人物按正常速度经过。

预期核心点可见度和`valid_frame_ratio`下降；严重时输出`tracking_lost`。这组永远不能进入个人基线。

### Q02：逐步出画，3条

| 时间 | 动作 |
|---:|---|
| 0–2秒 | 全身位于起点 |
| 2–8秒 | 正常横向行走 |
| 8–12秒 | 继续走出画面，使半身到全身逐步不可见 |
| 12–15秒 | 保持出画，不重新进入 |

预期跟踪质量下降或出现`tracking_lost`，不得输出可信异常步态结论。

## 七、三日个人基线综合片脚本

必须覆盖三个真实不同日期。若没有8月1日和8月2日的正常录像，不得补写日期；建议经项目组书面确认后使用8月3、4、5日。

每天拍1条约60秒综合片，文件名：

```text
20260803_P01_BASELINE_COMPOSITE_C6C_POS01_15FPS_01.mp4
20260804_P01_BASELINE_COMPOSITE_C6C_POS01_15FPS_01.mp4
20260805_P01_BASELINE_COMPOSITE_C6C_POS01_15FPS_01.mp4
```

| 时间 | 动作 | 提取目标 |
|---:|---|---|
| 0–5秒 | 在左起点自然站立 | 稳定角度与初始质量 |
| 5–15秒 | 正常步行左→右8—12步 | 正常相对步速 |
| 15–20秒 | 右终点稳定站立 | 稳定角度 |
| 20–30秒 | 正常步行右→左8—12步 | 方向复核与相对步速 |
| 30–35秒 | 回到椅子前自然站立 | 动作切换 |
| 35–40秒 | 正常速度坐下 | 坐站完整性 |
| 40–45秒 | 自然坐稳 | 起身前基线 |
| 45–49秒 | 正常速度起身，不抢快 | 正常起身时长 |
| 49–60秒 | 自然稳定站立 | 稳定躯干角度 |

要求：

- 三天使用同一`resident_id/device_ref/camera_position_id`；
- 摄像机地面标记、角度、焦距、分辨率和帧率不变；
- 每天都记录机内时间戳；
- 当天若出现快速起身、危险摇晃、遮挡、低质量或ORANGE状态，整条不得作为基线，应重新拍摄；
- 状态只能标记为`PROVISIONAL/初步基线`，不能称为稳定医学基线。

## 八、起身与恢复控制组脚本

### R01：快速起身单独出现，再补2条

每条20秒：

| 时间 | 动作 |
|---:|---|
| 0–5秒 | 自然坐稳，双脚落地 |
| 5–7秒 | 在0.8—1.2秒内快速但可控起身 |
| 7–20秒 | 稳定站立，不摇晃、不走动、不扶墙 |

预期：只生成可用`rapid_rise`时保持GREEN，不创建RiskEvent。若测试者出现明显摇晃，该条作废，不得仍标为快速起身单例。

### R02：缓慢起身，3条

每条18秒：

| 时间 | 动作 |
|---:|---|
| 0–5秒 | 自然坐稳 |
| 5–9秒 | 用约2.5—3.5秒连续完成起身，不中途停顿 |
| 9–18秒 | 稳定站立 |

预期：起身时长明显大于R01，作为`slow_rise`方向验证。不要故意表现疼痛或失衡。

### R03：恢复不足15秒，再补2条

每条约25秒：

| 时间 | 动作 |
|---:|---|
| 0–5秒 | 站立并做可控躯干摇晃 |
| 5–8秒 | 在保护下坐回固定椅子 |
| 8–21秒 | 连续稳定约12—13秒 |
| 21–25秒 | 结束录像，确保片内稳定时间真实少于15秒 |

预期：在已有ORANGE/INTERVENING事件前提下仍保持INTERVENING。稳定时长必须由连续帧计算，不把12—14秒改成15秒。

## 九、完整黄金闭环脚本

至少拍2条，每条110—120秒。文件名：

```text
20260803_P01_GOLDEN_FULL_LOOP_C6C_POS01_15FPS_01.mp4
20260803_P01_GOLDEN_FULL_LOOP_C6C_POS01_15FPS_02.mp4
```

### 分镜时间轴

| 时间 | 演员动作 | 系统验收含义 |
|---:|---|---|
| 0–8秒 | 自然坐姿静止，双脚落地，手自然放置 | 正常开头和质量检查 |
| 8–10秒 | 做准备动作，但不要提前明显摇晃 | 分隔正常与起身 |
| 10–12秒 | 在0.8—1.2秒内快速、可控起身 | `rapid_rise`候选 |
| 12–22秒 | 站立状态下做明显但可控的躯干左右摇晃 | 30秒内`trunk_sway`组合，预期ORANGE |
| 22–28秒 | 在保护下缓慢坐回固定椅子 | 干预阶段 |
| 28–30秒 | 调整到自然稳定坐姿 | 稳定计时尚未开始 |
| 30–45秒 | 连续保持自然稳定15秒，不抬手、不挪椅子 | `posture_recovered.current_value=15秒`，进入OBSERVING |
| 45–105秒 | 继续稳定观察完整60秒 | 无新危险时进入RESOLVED |
| 105–115秒 | 继续保持稳定，留10秒缓冲 | 防止编码结尾截断 |
| 115秒后 | 摄影负责人结束录制 | 完整闭环结束 |

### 黄金片段硬门槛

- `rapid_rise`与`trunk_sway`片内时间差不超过30秒；
- 两条Evidence的`confidence`与`data_quality`均不低于0.70；
- 至少一条`confidence`不低于0.80；
- `posture_recovered.current_value`只写连续稳定秒数；
- 恢复角度另存`stable_trunk_angle_deg` Observation；
- 稳定15秒之后还要完整观察60秒；
- 观察期内不能再次快速起身、摇晃、出画、被遮挡或出现其他危险动作；
- 工具干预成功不等于事件解除，必须靠真实恢复和观察完成闭环。

### 现场安全口令

保护人员不入镜但站在椅子侧后方。出现以下任一情况立即停止：真实头晕、脚下不稳、椅子移动、测试者碰撞家具、保护人员必须入镜搀扶、摄像机移动、无关人员进入路线。

停止后该条标记`ABORTED`，不得剪掉失败部分冒充连续成功。

每条录完立即检查：

- [ ] 机内时间戳正确；
- [ ] 只有P01一名主测试者；
- [ ] 动作区间内头、肩、髋、膝、踝和脚完整可见；
- [ ] 人物高度占画面55%—80%；
- [ ] 双脚着地点清晰，无持续拖影；
- [ ] 摄像机没有转动、追踪、变焦或抖动；
- [ ] 正常和异常动作标签未混淆；
- [ ] 文件名、方向、重复序号正确；
- [ ] `simulated=true`、授权状态和保留期限已记录；

## 十二、必须补拍的情况

- 头或任一脚在主要动作区间出画；
- 椅子遮挡双髋或双脚，导致无法判断起身；
- 正常步态不足8步或不足4个完整周期；
- 快速起身单例中出现独立明显摇晃；
- 黄金片段稳定满15秒后不足60秒；
- 黄金观察期间出现新危险动作；
- 相机自动追踪、数码变焦或位置发生改变；
- 无关人员进入画面并干扰单人姿态；
- 低照度、逆光、严重拖影或文件损坏；
- 场景标签和实际动作不一致；
- 真实稳定不足15秒却在清单中写成15秒。
