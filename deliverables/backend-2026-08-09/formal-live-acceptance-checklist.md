# 正式实机验收清单

此清单在具备正式环境后执行。不得把临时隧道、未签名测试模式或 Mock 工具结果标为正式实机通过。

## 前置条件

- 固定公网 HTTPS 后端地址已部署；
- 萤石平台已配置正式回调地址；
- 已按官方规则配置并验证 Webhook 签名；
- `EZVIZ_WEBHOOK_ALLOW_UNSIGNED_TEST=false`；
- 凭证只存在部署环境的 `.env` 或受控密钥服务；
- 设备、素材、音频及模拟标识均有授权记录。

## 执行顺序

1. 调用 `/health`，记录版本与时间；
2. 从萤石平台触发一次告警，确认 Webhook 返回成功并写入告警日志；
3. 使用一段授权 C6c 素材，按 Asset → Observation → Evidence 提交；
4. 查询事件和 RuleTrace，确认证据、来源、规则版本和状态一致；
5. 若 Evidence 确实满足规则，执行干预并记录结果；
6. 提交真实恢复或家属核验结果，按对应场景检查 OBSERVING / RESOLVED；
7. 重复提交同一 Evidence，确认不重复创建事件或执行工具；
8. 保存脱敏 HTTP 响应、事件详情、页面截图、失败与降级记录。

## 分项结论要求

- **回放接入通过**：Asset、Observation、Evidence 可追溯且实际入库；
- **状态机闭环通过**：素材真实满足规则，并完成事件、干预、恢复和回落；
- **正式萤石回调通过**：固定 HTTPS、官方验签与平台推送均成功；
- **自动设备闭环通过**：仅当萤石告警确实自动触发算法、算法自动提交结果并完成后端事件流程时才可声明。
