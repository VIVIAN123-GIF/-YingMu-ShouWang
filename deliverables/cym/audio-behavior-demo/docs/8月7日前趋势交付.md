# 8月7日前趋势交付

## 结论

已完成任务看板中常易铭的“昼夜节律与多日趋势”代码交付。实现位于`src/trend_analysis.py`，可把日活动汇总转换为符合Freeze v1.0的Observation和Evidence；算法不输出最终风险等级，不作心理疾病诊断。

## 输入与基线

输入样例是`samples/mock_daily_activity.json`。每个日汇总包含：

- 日期；
- 访问区域数；
- 房间转换数；
- 白天和夜间活动分钟数；
- 当日数据质量。

最后一日是当前日，前面的日汇总构成个人基线。基线使用滚动中位数和MAD：

| 历史日数量 | 状态 | 输出 |
|---:|---|---|
| 少于3日 | `INSUFFICIENT` | 仅Observation，不生成长期Evidence |
| 3至6日 | `PROVISIONAL` | 仅Observation，不生成长期Evidence |
| 不少于7日 | `STABLE` | 可生成长期趋势Evidence |

该保护避免用过少样本把偶然变化解释为长期趋势。高风险、低质量或未通过人工复核的数据在正式接入时不得进入正常基线；当前样例全部是`MOCK`，仅用于接口联调。

## 输出

稳定基线且当前值满足异常条件时，生成：

| Evidence | 条件 | 边界 |
|---|---|---|
| `activity_range_decline` | 当前访问区域数低于基线中位数 | 仅提示活动范围变化 |
| `room_transition_decline` | 当前房间转换数低于基线中位数 | 仅提示日常活动变化 |
| `day_night_rhythm_change` | 当前昼间活动占比与基线相差至少0.20 | 仅提示作息变化 |

所有Evidence均引用对应的“基线值”和“当前值”Observation，并继承`resident_id`、`source_mode`和`simulated`。`baseline_deviation`使用以MAD缩放的稳健偏离值；`severity`只是该特征异常程度，不是最终风险等级。

## 运行

在`deliverables/cym/audio-behavior-demo`目录执行：

```powershell
python .\src\generate_trend_samples.py `
  --input .\samples\mock_daily_activity.json `
  --output .\output\trend_evidence_bundle.json

python .\src\submit_to_backend.py `
  --bundle .\output\trend_evidence_bundle.json `
  --base-url http://127.0.0.1:8000 `
  --log-output .\output\trend_submission.json
```

先启动后端：

```powershell
python -m uvicorn backend.main:app --reload
```
