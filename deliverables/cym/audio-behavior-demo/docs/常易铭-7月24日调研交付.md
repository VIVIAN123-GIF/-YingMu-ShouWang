| 项目 | 内容 |

### 1.1 一页结论

Whisper本地转写和OpenCV人员/轨迹最小Demo均已在本机跑通，可以作为后续语音与行为Evidence适配器的技术起点。

- **语音方向可行**：Whisper `tiny` 模型能够在本地完成中文录音转写，并识别出“保证收益”等高风险交互词。当前结果存在“验证码→验证马”“马上完成转账→马上完全转张”等同音或近音错误，因此不能只做严格字符串匹配，也不能由单个关键词直接判定诈骗。
- **行为方向有条件可行**：OpenCV HOG可以在人物完整、直立、距离约2—3米且光线较好的条件下检测到人员；MOG2活动量、人物中心轨迹、累计移动距离和当前行为标签已跑通。HOG对近距离、人体截断、遮挡和姿态变化较敏感，适合最小Demo，不作为最终访客身份识别方案。
- **接口方向可行**：语音和行为模块只生成Freeze v1.0规定的Observation/Evidence，不直接输出GREEN、YELLOW、ORANGE或RED等级。最终风险等级由统一风险引擎结合其他证据决定。
- **今日交付边界**：`fraud_keyword`接口样例来自模拟话术的音频文件回放；公开可复现验收使用Windows TTS合成音频，历史本人授权录音不进入仓库。`activity_range_decline`和`unauthorized_visitor`因缺少真实多日区域数据及人员授权数据，使用明确标注的MOCK样例。所有样例均为模拟实验数据，不宣称是真实音频监测或真实居家连续监测结果。

## 二、技术选择与边界

### 2.1 推荐方法

- 语音转写：本地`openai-whisper`，当前以`tiny`模型验证流程，后续根据延迟与准确率测试选择`base`或`small`。
- 关键词检测：文本归一化、关键词/近义短语词典和上下文组合规则；保留命中词、时间和原始转写，便于追溯。
- 人员与轨迹：当前使用OpenCV HOG完成人员检测，以最大人体框几何中心作为单人轨迹点，并使用指数平滑降低抖动。
- 活动量：MOG2背景建模获得画面运动面积；结合短窗口轨迹距离区分`STILL`、`WALKING`和`HIGH MOVEMENT`。
- 统一输出：先生成Observation，再由行为或语音适配器生成Evidence；Evidence只表达异常特征及置信度，不直接决定风险等级。

### 2.2 暂不推荐的方法

- 不使用单一高风险词直接判断诈骗；它只能形成一条`fraud_keyword`证据。
- 不使用语音流畅度直接生成心理疾病或认知障碍证据。
- 不把HOG检测到“有人”等同于“非授权访客”；`unauthorized_visitor`还需要与授权人员名单、来访登记或人工确认结合。
- 不用当前单摄像头像素距离直接宣称真实米制活动距离；未完成场景标定前统一保留像素或区域级统计。
- 不由本模块输出最终风险水位，避免越过统一状态机。

## 四、最小Demo与运行结果

> 说明：本上传准备包已经附带Whisper和OpenCV最小Demo源码，但不包含`.venv`、模型缓存、原始录音、账号密钥或设备敏感信息。

### 4.1 Whisper本地转写Demo

**包内脚本**：`src\whisper_demo.py`

**输入素材**：`test_scam.m4a`

**启动命令**：

```powershell
.\.venv\Scripts\Activate.ps1
python .\src\whisper_demo.py "C:\path\to\authorized_test_audio.m4a" `
  --model tiny `
  --language Chinese `
  --output-dir .\output
```

**实际输出文件**：`output\test_scam.txt`

**实际转写结果**：

```text
您好我是社區健康服務人員現在有一個免費的養腦投資項目可以保證收益
請把驗證馬告訴我並馬上完全轉張
```

**结果说明**：

- “保证收益”被正确识别，可形成高风险交互词命中；
- “验证码”被识别成“验证马”，“完成转账”被识别成“完全转张”，说明严格字面匹配会漏报；
- 后续采用简繁归一化、同音/近义短语词典和组合上下文规则；
- 当前Demo证明“本地音频→中文文本”的链路可行，不证明能够准确判断真实诈骗。

### 4.2 OpenCV人员与轨迹Demo

**包内脚本**：`src\behavior_demo.py`

**启动命令**：

```powershell
.\.venv\Scripts\Activate.ps1
python .\src\behavior_demo.py --input 0 --max-seconds 30
```

本地MP4无窗口复现：

```powershell
python .\src\behavior_demo.py `
  --input .\output\smoke.mp4 `
  --headless `
  --summary-output .\output\behavior_summary.json `
  --simulated
```

摄像头窗口可按`q`退出；MP4播放结束、达到帧数或时间上限时自动退出。

**当前输出**：

- `Persons`：当前帧通过阈值的HOG人体框数量；
- `Motion area`及`Activity`：MOG2画面运动面积和LOW/MEDIUM/HIGH活动等级；
- 紫色中心点与轨迹：最大人体框几何中心的平滑轨迹，保留最近80个点；
- `Travel distance`：本次运行中相邻平滑轨迹点的累计像素距离；
- `Behavior`：基于最近约40个轨迹步长的STILL/WALKING/HIGH MOVEMENT标签。
- JSON运行摘要：输入类型、帧数、检测帧数、活动量、像素轨迹和退出原因，不保存画面或绝对路径。

**实测结果**：

- 完整、直立、距离适中时，`Persons`可由0变为1；走出再进入画面时可观察到约`1→0→1`；
- 站立不动时活动量降低，走动时活动量明显变化；
- 紫色轨迹能够跟随人物中心移动；
- 本地合成MP4可在无窗口模式处理60帧并以`video_eof`正常结束；
- MOG2分析使用未绘制的原始帧，显示框和文字不会进入运动区域计算；
- 人物过近、身体被画面截断、明显遮挡或非直立时，HOG可能漏检并显示`Persons: 0`；
- 当前行为标签阈值只用于Demo，尚未经过数据集或多人验证，不作为正式风险判断阈值。

## 五、Freeze v1.0 Evidence样例

### 5.1 活动范围下降：`activity_range_decline`

场景：模拟张爷爷长期个人基线通常覆盖4个已标定生活区域，最近7天平均只覆盖2个区域。该证据只表示长期活动范围相对个人基线缩小，不作心理诊断。

```yaml
schema_version: "1.0"
evidence_id: "evi-mental-activity-range-20260724-0001"
observation_ids:
  - "obs-tracking-baseline-range-20260724-0001"
  - "obs-tracking-current-range-20260724-0002"
resident_id: "resident-001"
timestamp: "2026-07-24T10:00:00+08:00"
risk_domain: "MENTAL"
evidence_type: "activity_range_decline"
severity: 0.62
confidence: 0.78
data_quality: 0.82
baseline_value: 4.0
current_value: 2.0
baseline_deviation: -1.8
time_scale: "LONG"
location: null
explanation: "模拟近7日平均活动区域数由个人基线4个降至2个，仅提示长期活动范围缩小，建议结合外出、生病和家属反馈复核"
adapter_version: "behavior-adapter-v1"
source_mode: "MOCK"
simulated: true
```

字段单位：`baseline_value`和`current_value`为平均每日活动区域数，`baseline_deviation`为相对滚动基线的标准化偏离值。

### 5.2 非授权访客：`unauthorized_visitor`

场景：模拟客厅出现一名无法与授权人员名单匹配的访客。该证据只建议家属进行身份核验，不表示系统已经确认对方是诈骗人员。

```yaml
evidence_id: "evi-fraud-visitor-20260724-0001"

  - "obs-visitor-detection-20260724-0001"
  - "obs-visitor-authorization-check-20260724-0002"
resident_id: "resident-001"
timestamp: "2026-07-24T14:20:00+08:00"
risk_domain: "FRAUD"
evidence_type: "unauthorized_visitor"
severity: 0.55
confidence: 0.74
data_quality: 0.80
baseline_value: null
current_value: 1.0
baseline_deviation: null
time_scale: "SHORT"
location: "living_room"
explanation: "模拟检测到1名未匹配授权名单的访客，身份尚未确认，建议家属核验"
adapter_version: "behavior-adapter-v1"
source_mode: "MOCK"

```

字段单位：`current_value`为当前未匹配授权人员数量。真实实现必须由人员检测结果与授权名单、来访登记或人工确认共同生成，不能仅依赖HOG人体框。

### 5.3 高风险交互关键词：`fraud_keyword`

场景：对已授权录制的模拟诈骗话术进行本地Whisper转写，出现“保证收益”等高风险词，并存在与“验证码”“马上转账”近音的转写片段。该证据只表示高风险交互特征，不直接判断真实诈骗。

```yaml
schema_version: "1.0"
evidence_id: "evi-fraud-keyword-20260724-0001"
observation_ids:
  - "obs-audio-transcript-20260724-0001"
  - "obs-fraud-keyword-match-20260724-0002"
resident_id: "resident-001"
timestamp: "2026-07-24T15:10:00+08:00"
risk_domain: "FRAUD"
evidence_type: "fraud_keyword"
severity: 0.72
confidence: 0.84
data_quality: 0.78
baseline_value: null
current_value: 3.0
baseline_deviation: null
time_scale: "SHORT"
location: "living_room"
explanation: "模拟录音转写命中‘保证收益’，并出现与‘验证码’‘马上转账’近音的高风险交互片段，需要结合访客与停留证据核验"
adapter_version: "speech-adapter-v1"
source_mode: "RECORDED_REPLAY"
simulated: true
```

字段单位：`current_value`为本段音频中进入复核的高风险词或近音短语数量；分数为当前调研样例值，后续须由标注数据校准。

## 六、置信度与数据质量草案

| 对象 | confidence草案 | data_quality草案 |
|---|---|---|
| `activity_range_decline` | 区域识别有效率、跨日覆盖率和基线样本量的加权结果 | 有效追踪帧比例、遮挡率、摄像头在线率和区域标定完整度 |
| `unauthorized_visitor` | 人员检测置信度与授权匹配结果的组合；缺少身份依据时不得给高置信度 | 人体完整度、遮挡、照度、连续检测时长和画面清晰度 |
| `fraud_keyword` | Whisper片段置信信息、关键词匹配强度及多词组合一致性 | 信噪比、有效语音比例、削波、静音占比和转写完整度 |

当前三个样例的分数用于接口联调，不是经过实测标定的性能结论。7月31日前先冻结计算方式，8月测试阶段再以标注样本校准阈值。

## 八、主要风险与降级方案

| 风险/失败信号 | 影响 | 降级处理 |
|---|---|---|
| 单个关键词在正常语境中出现 | 产生诈骗误报 | 单关键词仅生成低到中等置信Evidence，不独立升级风险；要求访客、停留或多个组合词进入同一时间窗后由统一状态机判断 |
| Whisper同音错字、简繁差异 | 严格匹配漏报 | 进行简繁与标点归一化，增加近音/近义短语词典；保留原始转写供人工复核，不自动改写为“确定诈骗” |
| 音频噪声大、静音多或转写不完整 | 关键词结果不可靠 | 降低`data_quality`和`confidence`；低于门槛时输出`audio_quality_low`系统/语音质量证据，不让该片段参与高等级判断 |
| HOG在近距离、截断、遮挡或非直立姿态下漏检 | 人数和轨迹不连续 | 降低数据质量与置信度并保留漏检日志；轨迹统计忽略无效段，后续评估更稳健的人体检测器；失败时使用带来源标记的回放或MOCK完成接口联调 |
| 仅凭人体框无法判断是否授权 | 把普通来访误报为可疑人员 | HOG只生成“人员出现”Observation；必须经过授权名单、来访登记或人工确认后才能生成`unauthorized_visitor` |
| 单摄像头像素距离受透视影响 | 活动范围统计失真 | 7月28日前采用人工区域多边形与房间/区域转换，不把像素距离解释为真实米数 |
| 缺少长期真实居家数据 | 无法验证心理长期趋势 | 使用明确标记的MOCK多日统计完成接口和页面验证，后续只报告模拟实验结果，不作医学诊断 |
