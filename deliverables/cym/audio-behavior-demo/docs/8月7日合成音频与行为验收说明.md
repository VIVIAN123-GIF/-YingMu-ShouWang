# 8月7日合成音频与行为验收说明

## 1. 结论

本次验收使用Windows TTS合成语音和程序生成的移动图形MP4，只验证语音/行为模块的输入、处理、Observation输出和来源标记。所有场景均为模拟实验，不是实际老人居家连续监测，也不代表系统识别出真实诈骗、心理异常或人体行为风险。

## 2. 来源标记规则

`source_mode`描述数据怎样进入系统，`simulated`描述场景是否为模拟。两者不能互相替代。

| 输入 | `source_mode` | `simulated` | 原因 |
|---|---|---:|---|
| Windows TTS生成的WAV文件，经文件回放进入Whisper | `RECORDED_REPLAY` | `true` | 输入形态是已生成音频文件回放，内容和声音均为合成 |
| 程序生成的移动图形MP4，经文件回放进入OpenCV | `RECORDED_REPLAY` | `true` | 输入形态是视频文件回放，且不含真人 |
| 人工构造的多日活动、授权名单或停留统计JSON | `MOCK` | `true` | 没有对应音视频采集，只用于规则和接口联调 |
| 摄像头下成员执行预先设计的测试动作 | `LIVE_DEVICE` | `true` | 输入来自实时设备，但动作是模拟实验 |
| 真实日常连续采集 | `LIVE_DEVICE` | `false` | 当前算法包没有此类共享验收结果 |

因此，`RECORDED_REPLAY + simulated: true`不等于真实录音监测，`LIVE_DEVICE + simulated: true`也不等于真实风险事件。

## 3. 合成音频验收

### 3.1 输入

- 文本：`samples/test_scam_script.txt`；
- 生成工具：`scripts/generate_test_audio.ps1`；
- 音频性质：Windows本地TTS合成，不含真人声音；
- 音频文件：仅生成到被Git忽略的`output/`，不进入共享仓库；
- 来源：`RECORDED_REPLAY`；
- 模拟标记：`simulated: true`。

### 3.2 运行

```powershell
& .\scripts\generate_test_audio.ps1 `
  -OutputPath output/synthetic_test_20260807.wav

python .\src\whisper_demo.py `
  .\output\synthetic_test_20260807.wav `
  --model tiny `
  --language Chinese `
  --observation-output .\output\synthetic_audio_observations_20260807.json `
  --resident-id resident-001 `
  --asset-id asset-synthetic-audio-20260807 `
  --source-mode RECORDED_REPLAY `
  --simulated
```

### 3.3 2026年8月7日结果

- WAV生成成功；
- Whisper `tiny`完成中文转写；
- 输出4条Freeze v1.0 Observation；
- 命中`guaranteed_return`、`verification_code_like`和`immediate_transfer`三类话术；
- 转写仍包含“养老→杨老”“验证码→验证马”等近音误差；
- 所有Observation均为`RECORDED_REPLAY + simulated: true`。

该结果只证明“合成文件回放→Whisper→关键词特征→Observation”链路可运行。它没有验证麦克风连续收音、真实环境噪声适应、真实诈骗识别、真实人员身份或风险等级判断。

## 4. 合成行为验收

### 4.1 输入

- 生成工具：`scripts/generate_test_video.py`；
- 视频内容：黑色背景上的移动圆点，不含真人或人体轮廓；
- 视频文件：仅生成到被Git忽略的`output/`；
- 来源：`RECORDED_REPLAY`；
- 模拟标记：`simulated: true`。

### 4.2 运行

```powershell
python .\scripts\generate_test_video.py `
  --output .\output\synthetic_behavior_20260807.mp4 `
  --seconds 4 `
  --fps 15

python .\src\behavior_demo.py `
  --input .\output\synthetic_behavior_20260807.mp4 `
  --headless `
  --summary-output .\output\synthetic_behavior_summary_20260807.json `
  --observation-output .\output\synthetic_behavior_observations_20260807.json `
  --resident-id resident-001 `
  --asset-id asset-synthetic-behavior-20260807 `
  --simulated
```

### 4.3 2026年8月7日结果

- 生成并处理60帧；
- `stop_reason`为`video_eof`，正常自动退出；
- `source_mode`为`RECORDED_REPLAY`，`simulated`为`true`；
- `detected_frames`为0、`track_points`为0，符合“不含人物”的输入设计。

该结果只证明“生成MP4→OpenCV读取→运动区域计算→EOF→Observation”链路可运行。它不能证明HOG人物检测、人员轨迹、区域转换或真实行为风险识别效果。

## 6. 允许与禁止的对外表述

允许：

- “使用合成音频文件回放验证了本地Whisper转写和关键词Observation链路”；
- “使用不含人物的生成MP4验证了视频读取、自动退出和行为Observation输出”；
- “使用MOCK统计验证了长期趋势和访客Evidence的契约与后端兼容性”。

禁止：

- “系统已完成真实老人音频监测”；
- “系统在真实通话中识别出诈骗”；
- “合成圆点视频证明了人物检测或行为识别准确率”；
- “MOCK多日统计证明老人出现心理健康问题”。

脱敏机器可读结果见`logs/synthetic_acceptance_20260807.json`。
