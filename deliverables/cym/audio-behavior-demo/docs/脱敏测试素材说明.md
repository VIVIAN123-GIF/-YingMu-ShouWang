# 脱敏测试素材说明

## 语音素材

- 素材性质：经本人授权录制的模拟高风险话术；
- 使用目的：验证本地Whisper中文转写和关键词检测可行性；
- 输入来源：`RECORDED_REPLAY`；
- 模拟标记：`simulated: true`；
- 原始文件：`test_scam.m4a`，只保存在本机，不上传GitHub；
- GitHub中只保留脱敏转写文本和测试结果。

模拟话术包含“免费项目”“保证收益”“验证码”“马上转账”等研究用表达。它不对应真实诈骗事件，也不包含真实人员姓名、联系方式、账号、设备信息或支付信息。

实际转写见：

```text
samples/test_scam_transcript.txt
```

负责人复现时应使用自己经过授权的测试音频，不应要求上传原始私人录音。

如没有可共享录音，可在Windows本地运行：

```powershell
powershell -ExecutionPolicy Bypass `
  -File .\scripts\generate_test_audio.ps1
```

脚本读取`samples/test_scam_script.txt`并生成`output\synthetic_test.wav`。该文件由本机语音合成，不包含真人声音，只用于输入链路测试；发音和识别效果取决于本机已安装语音包。

## 行为素材

- 素材性质：本机摄像头下由本人完成的站立、静止、左右走动和进出画面动作；
- 使用目的：验证人员检测、活动量变化和中心轨迹；
- 原始视频：未录制、未上传；
- 保存内容：仅保留文字化测试结论，不包含人脸截图、家庭环境图片和摄像机信息。

仓库提供`scripts/generate_test_video.py`生成移动圆点MP4。该视频不含人物，只验证本地MP4读取、自动退出和运行摘要，不用于证明HOG人物检测效果。

## 后续集中拍摄要求

需要心理或诈骗场景素材时，应提前提交：测试目的、动作脚本、机位、光照、是否录音、重复次数、命名规则和验收标准。素材必须标明`RECORDED_REPLAY`和`simulated: true`，不得包装成真实居家风险事件。
