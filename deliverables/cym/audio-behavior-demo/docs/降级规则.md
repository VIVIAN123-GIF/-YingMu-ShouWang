# 语音与行为模块降级规则

## 1. 单关键词误报

失败信号：正常语境中出现“验证码”“转账”等单个词。

处理：

- 单个词只生成低到中等置信度的`fraud_keyword` Evidence；
- 不直接输出最终风险等级；
- 要求多个高风险表达，或访客、停留、异常踱步等证据进入同一时间窗；
- 保留原始转写和命中片段供人工核验。

## 2. Whisper错字和简繁差异

失败信号：出现“验证码→验证马”“完成转账→完全转张”等近音结果。

处理：

- 做简繁、标点、空格和大小写归一化；
- 增加近音词、近义词和组合短语词典；
- 不擅自把转写结果改写成“确定诈骗”；
- 低置信片段只进入复核，不独立升级风险。

## 3. 音频质量低

失败信号：噪声大、静音多、削波、声音过小或转写严重不完整。

处理：

- 降低`data_quality`和`confidence`；
- 低于门槛时输出`audio_quality_low`；
- 该片段不参与高等级判断；
- 保留失败原因并请求更清晰的授权音频或使用MOCK完成接口联调。

## 4. HOG漏检

失败信号：人物过近、身体被截断、遮挡、非直立或离开画面时`Persons: 0`。

处理：

- 降低行为Observation的数据质量与置信度；
- 无效帧不进入活动范围和停留统计；
- 记录漏检条件，不用0值代替缺失观测；
- 后续评估更适合遮挡和近距离的人体检测器；
- 无法复现时使用明确标记的回放或MOCK，不伪装成实测结果。

## 5. 无法确认访客身份

失败信号：画面中检测到人体，但缺少授权人员名单、来访登记或人工核验。

处理：

- HOG只生成“人员出现”Observation；
- 不直接生成高置信度`unauthorized_visitor`；
- 等待授权名单比对或家属人工核验；
- 输出解释必须写“身份尚未确认”。

## 6. 单摄像头像素距离失真

失败信号：人物远近变化导致像素轨迹距离不能对应真实米数。

处理：

- 不把`Travel distance`解释为真实米制距离；
- 7月28日前使用人工多边形区域和区域转换；
- 未标定时只报告像素或区域级统计。
