# OpenCV行为Demo实测记录

## 环境

- 日期：2026年7月24日；
- OpenCV：5.0.0；
- 输入：本机摄像头；
- 画面：480×640×3；
- 素材状态：本人授权现场动作，不保存和上传原始视频。

## 实测结果

| 测试 | 结果 | 状态 |
|---|---|---|
| 摄像头读取 | `cap.read()`成功，能看到实时画面 | 通过 |
| 完整直立人体 | 距离约2—3米时`Persons: 1` | 通过 |
| 人员进出画面 | 可观察到约`1→0→1` | 通过 |
| 静止与走动 | `Activity`随运动发生明显变化 | 通过 |
| 中心轨迹 | 紫色圆点位于人体框中心，轨迹随人物移动 | 通过 |
| 近距离/截断人体 | 可能出现`Persons: 0` | 已知限制 |
| 行为标签 | 可显示STILL/WALKING/HIGH MOVEMENT | Demo通过，阈值待标定 |

## 运行时间

程序以实时窗口持续运行，直到用户按`q`退出。本次测试未形成可复现的FPS或单帧推理延迟数据，因此不将“实时”写成性能指标；后续使用本地MP4和计时日志统一测量。

## 结论

OpenCV/HOG人员检测、MOG2活动量和单人中心轨迹链路已经跑通。HOG对完整人体、距离、遮挡和姿态敏感，当前结果属于可行性Demo，不代表人物检测稳定性已经达标。
